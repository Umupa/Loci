# Contributing

The rules for working in this repository are in [AGENTS.md](AGENTS.md). They apply to people and to coding agents alike.

A dmg is built, signed, notarized and released from a tag; how, and which secrets that needs: [docs/releasing.md](docs/releasing.md).
