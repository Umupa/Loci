# 派活

把一件事交给另一个 agent 时，说明照这个结构写。对方只知道这份说明和仓库里的文件。

```
目标
  一两句话：做完之后，用户或调用方能做到什么。

场景
  docs/features.md 里的编号，例如 α1-S3、α1-S6。没有对应场景就先补场景。

范围
  要动的模块。明确写出不做什么。

已知
  已经定了的设计（指向 docs/design.md 的小节）、已经排除的做法、
  旧版里可参考的行为（git show main:<路径>，只看行为）。

交付
  - 验证命令和结果
  - 每条场景怎么验证的；界面改动附 output/snapshots 里的图
  - 没做完或没验证的事
  - 这次有没有哪条纠正变成了检查
```

规则不用在说明里重复，仓库根目录的 `AGENTS.md` 对方会读。
