# Loci 的设计

> 写的是现在的样子。要做什么在 [roadmap.md](roadmap.md)，功能叫什么在 [features.md](features.md)，代码怎么分在 [architecture.md](architecture.md)，伙伴在 [agent.md](agent.md)。

## 已定的事

| 问题 | 决定 |
|---|---|
| 产品 | 伙伴和资料库：和伙伴聊、一起读资料，也可以请它写课 |
| 资料归属 | 资料是独立的原子，属于资料库，不属于任何对话 |
| 媒体 | 视频与技术演讲、播客、文章、论文，粘链接即读 |
| 取回 | 应用只取回一个确定的链接（yt-dlp、正文提取、播客音频地址、论文 PDF），粘贴后几秒内就能开始读；找什么值得读不是应用的事 |
| 技术栈 | 全部 Swift，SwiftUI 加 AppKit，没有 WebView 界面 |
| 数据 | 内容是文件，状态在数据库；不兼容 Tauri 版的数据；上云先不做 |
| 平台 | 只做 macOS 26 及以上 |
| 命令行 | 没有 `loci` 命令行；伙伴通过文件和应用协作 |
| 提问 | 打开一份资料，右栏就是和伙伴在这份资料上的对话（陪读） |
| agent | 每份资料库只有一个伙伴；Soul、记忆、笔记、日记是 `agent/` 下的文件，所有 runtime 共用 |
| 不做 | RSS 与订阅、剪辑与导出、自由书写的笔记文档、Dock 角标数字、对话背景与主题壁纸、自定义快捷键（走系统设置）、文件树里的文件操作（交给访达） |

## 产品

### 伙伴与资料库

侧边栏第一项是伙伴，点它进主对话：一条一直聊下去的对话，资料库里发生的事（读完一份、存进一份）也出现在这里。粘一个链接或拖一个文件是「读这份材料」，进资料库并直接打开。

```
侧边栏              主区
─────────           ──────────────────────────────────
伙伴                主对话；再点一次进伙伴页：Soul、记忆、日记、定时、连接器、用量
资料库              画廊 → 打开一份资料
  视频              文章 / 论文：正文居中，右栏是和伙伴的对话与划线
  播客              视频 / 播客：播放器 + 随播放滚动的文稿
  文章
```

- 每份资料有自己的一条对话，右栏永远是伙伴。问答留在这份资料上，在这里聊过的事写进当天笔记，主对话里接得上。
- 用户看到的对话少，底下的会话多：换 runtime、Soul 变了、上下文满了，会话换新，对话不断。

### 划线：你读的时候留下的东西

划线、当时的想法、和伙伴的问答是同一种东西，叫一条划线：一个位置，加上可有可无的一句想法和几段问答。位置可以是一句话、一张图、一段时间，也可以是整篇——对整篇的想法也是一条划线，每份资料最多一条。它们单独存储，不写进资料。

| 内容 | 右栏的分页 |
|---|---|
| 文章 | 重点 · 对话 · 划线 |
| 论文 | 对话 · 划线 |
| 视频 | 文稿 · 重点 · 对话 · 划线（重点也标在进度条和文稿里） |
| 播客 | 重点 · 对话 · 划线（文稿就是单集页本身） |

- **划线**页最顶上是对整篇的想法，下面按原文顺序列出每一条：划的那句话或那张图、你的想法、问了什么、伙伴怎么答的。点一条，正文或播放位置跳过去；选中的那条底部就能写想法。
- 划到图片时记下图片在资料正文里的地址（Markdown 图片括号里那串），右栏显示缩略图，伙伴拿到的是图片在资料文件夹里的路径。
- **重点**是你点了「挑重点」后伙伴替一份视频、播客或文章挑的几段，带标题和对你说的理由；段数和运行时可选，可以只看重点。它是资料的一部分，和你的划线分开。
- 正文里只留划线本身，内容都在右栏。文字和音视频是同一套做法。
- 陪读的伙伴读得到这些划线，知道你在哪里停过、想过什么。

### 一份视频或播客经过什么

```
链接 / 文件 → 取回 → 转录 → 断句 → 翻译 → 章节 → 可读（重点点了才挑）
```

- 每一步的产物都是资料文件夹里的一个文件，任务可中断、可续做。
- 取回之后就能播放；后面每完成一步，界面多出一样东西，不等全部做完。
- 转录在本机做。翻译、章节和重点走本机的 agent CLI，不另配 API key。
- 文稿每一句都能划线、提问，定位符精确到秒。

### 语音识别与组件

参考 Vimpo 的做法。

**语音识别**用 whisper.cpp，模型按需下载，应用本身不带模型；七个型号照 Vimpo 列出，默认 Large v3 Turbo 压缩版（见下面「选型：照搬 Vimpo」）。

**组件**是应用自己不实现、要调用的外部程序：

| 组件 | 用途 | 来源 |
|---|---|---|
| yt-dlp | 取回视频和播客 | 系统里已有（如 Homebrew）就用它，没有则由 Loci 下载管理 |
| FFmpeg | 转封装、抽音轨 | 由 Loci 管理 |
| QuickJS | yt-dlp 解析部分站点需要 | 由 Loci 管理 |

- 都装在 `~/Library/Application Support/Loci/` 下，和模型放一起，不改动系统，也不进 `~/Loci`（那里只放用户的内容）。
- 设置里一页列出每个组件的版本和来源，可更新、可重新检测。yt-dlp 失效得快，取回失败时直接提示更新。
- 这些组件只有用到视频和播客时才需要，不影响只读文章的人。

## 设计

2026-11-17 改版，设计稿在 `output/sketches/redesign.html`（不提交）。质感参考 Vimpo 的暖黑与琥珀、hark 的对话，整体按 macOS 26 原生来做。之前的纸墨方向不再沿用。

| 方面 | 做法 |
|---|---|
| 底色 | 暗色暖黑（内容区约 `#121110`，卡片 `#1E1C19`），亮色暖白（内容区 `#FCFBF8`，卡片白）。两套单独调，跟随系统 |
| 强调色 | 琥珀（暗 `#EBA53A`，亮 `#D98E1F`），全应用一个。选中是琥珀的浅底（约 15%），不是实心色块；实心琥珀用在主按钮、发送、开关、勾选和开着的按钮上，上面的字是深色；旁边的次要按钮灰底，菜单悬停是灰底。样式都在 `Sources/LociUI/Design/Buttons.swift` |
| 外框 | 没有工具栏，内容顶到窗口上沿。侧边栏是悬浮的玻璃面板（离窗口边 8，圆角 14），红绿灯在它里面；弹层、菜单、选区工具条用系统玻璃 |
| 线 | 分隔线和描边都是 0.5 像素的细线；分组列表的分隔线从文字起点开始 |
| 字体 | 界面和正文用系统无衬线（SF Pro 与苹方）；资料标题、小节标题、伙伴的名字、Soul 与日记正文、引文用衬线（New York 与宋体）；版本、时间、路径、数量用等宽 |
| 控件 | 系统控件的样子：胶囊分段控件带卡片色滑块，弹出按钮带琥珀上下箭头，推按钮是白底细阴影；设置页照系统设置的分组列表 |
| 图标 | Dock 和 README 共用叠页图标：纸白色底板上，米白色纸页叠在琥珀色纸页前。菜单栏图标是同样两张纸的单色描线，伙伴在忙时后面那张填满。常用控件用 SF Symbols，不用 sparkles（规则在 `Tests/ArchitectureTests/Architecture.swift` 的 `forbiddenSymbols`）。侧边栏常态图标用暖灰，选中项用琥珀。yt-dlp 和 FFmpeg 用项目发布的图标，QuickJS 用花括号。Agent 标志使用原始颜色和相应的亮暗素材，安装状态由行尾标记区分 |
| 动效 | 系统弹簧；新消息上浮 10pt 淡入（0.45 秒，`cubic-bezier(.28,.67,.32,1)`），按下缩到 0.97，折叠用 0.3 秒弹簧 |
| 文字 | 不要副标题和解释性的小字，让布局说明自己 |

### 界面结构

设计稿在 `output/sketches/loci-agent.html`（不提交）。

- 侧边栏依次是伙伴、资料库和设置（见 [UI-S2](features.md#界面改版2026-11-17)），资料库一组在文章之后是课程。有新版本时侧边栏右下角多一个圆形更新按钮，平时不显示。
- 主对话是窗口打开的地方：消息是气泡，伙伴一条回复按空行分成几个；伙伴在对话里存的资料是资料卡，写的长内容是文档卡，单独成行的链接是链接卡，几张连着的卡叠成一摞。
- 主对话和面板栏作为一组居中，左右留白相等：对话是其中一栏，面板直接放在页面上，栏与栏之间只靠留白分开；面板、对话、栏宽都能拖，右上角的布局按钮一键换排法；窗口窄时远处的面板栏折成顶端一枚小胶囊，里面是各面板的来源小图标（见 [P-S12–P-S16](features.md#160面板)）。设计稿在 `output/sketches/companion-layout/index.html`（不提交）。
- 伙伴页：头像可以换，点名字可以命名、改名或清空，Soul（核心可编辑、长出来的特质）、记忆（MEMORY、USER、今天的笔记）、日记、定时（左边定时与面板刷新混排、点开看最近的 run，右边跟进；空的时候只有虚线框和图标）。设计稿在 `output/sketches/timers/index.html`（不提交）。
- 课程页是布面书画廊。输入「想学什么」打开写课卡片，左边是课程对话，右边随「目标 / 资料 / 写课」切换扉页、资料和书稿。阅读时左栏是图解、目录和资料链接，中间是图解或正文，右栏是同一门课的对话；有图解的课程打开先看到图解。完整场景见 [features.md 的课程](features.md#课程170) 和[课程图解](features.md#课程图解)。
- 资料的右栏是伙伴陪读：顶上只有居中的分段和收起按钮，对话与划线，消息样式与主对话一致，不用选人。
- 外语文章的阅读器右上角有翻译按钮，点了才翻。原文、对照、译文三档和视频字幕共用；对照时译文用无衬线和次要色跟在每段下面。划线和引文始终落在原文上，译文只是显示。
- 关掉所有窗口 Loci 不退出，留在菜单栏：点开是伙伴的头像、名字和在忙的事、下一个到点的定时，下面是打开 Loci、退出。菜单栏只看这台 Mac 上的伙伴。
- 伙伴的默认头像是翡翠色水面前的黑猫。圆形近景保留双耳和金绿色眼睛，换头像后各处一起更新。

流畅度定成可以测的预算：

| 指标 | 预算 |
|---|---|
| 冷启动到可操作 | 0.5 秒内 |
| 长文章、长文稿滚动 | 120 帧不掉 |
| 打开一份已缓存的资料 | 100 毫秒内出首屏 |
| 流式回复 | 不引起整页重排 |
| 空闲内存 | 200 MB 内 |

## 架构

模块、依赖和强制的规则在 [architecture.md](architecture.md)。这里只记几条选择：

- **界面只认 Host 协议。** 本机是进程内调用，远程是同一套命令走加密通道；以后的 iPhone 和 iPad 端也只是换一个界面。
- **命令层是唯一的入口。** 界面和远程都走它，测试直接调这一层。
- **伙伴通过文件和应用协作。** 记笔记、改用户档案、写日记、整理记忆，都是改 `agent/` 下的文件；应用监听到变化后更新界面。
- **阅读器**用 AppKit 加 TextKit 2：跨段落选区、划线、按引文重新定位、流式 Markdown 都压在这一个组件上。
- **状态**用 `@Observable` 和 Swift Concurrency，不引入额外的架构框架。
- **分发**走 Developer ID 签名公证，不上 Mac App Store：要启动用户自己装的 agent CLI，不能进沙盒。发布流程见 [releasing.md](releasing.md)。

## 数据

### 原则

1. **内容是文件。** 人能读，伙伴能直接写。
2. **状态在数据库。** 高频变化、需要查询的东西。
3. **镜像和索引可重建。** 删掉后能从文件重新生成。
4. **大文件永远只在本机。**

### 目录

```
~/Loci/
├─ agent/                     伙伴的一切，见 agent.md
├─ library/
│  └─ <短名>-<id>/
│     ├─ item.json            种类、标题、作者、来源链接、语言、时长、内容哈希、为什么收它
│     ├─ import.json          导入选择：保存到本地或在线看、画质、字幕、识别、翻译；没有就是保存到本地
│     ├─ content.md           文章正文；论文是 content.pdf
│     ├─ book.epub            书：拖进来的 EPUB 原样保存，读时直接从压缩包里取章节和图；TXT 书是 book.txt
│     ├─ images/              正文里的图
│     ├─ cover.*              封面
│     ├─ media.*              音视频
│     ├─ transcript.json      文稿：句、起止时间、说话人
│     ├─ translations/        译文：视频播客一句对一句，文章一段对一段
│     ├─ outline.json         章节
│     ├─ keypoints.json       重点：挑出的几段和挑时的运行时、段数
│     └─ .work/               任务的中间产物
├─ courses/
│  └─ <课程 id>/
│     ├─ course.json          目标、阶段、追问、资料、课时目录、已读课时与待处理动作
│     ├─ atlas.json           图解：总纲和积木，只能指向课程目录里的课时
│     ├─ lessons/<课时 id>.md  课文，保存后这课才能读
│     └─ notes/<课时 id>.jsonl  课时划线，只追加
├─ notes/
│  └─ library/<资料 id>.jsonl  一份资料上的划线，一行一条，只追加
├─ settings.json
├─ panels.json                面板的默认顺序（含「接着读」）、每个面板上次刷新的时间、你对盯着的面板里各行的态度、你最近删掉的条目；各栏怎么排是每台 Mac 自己的主页布局，存在本机偏好里
├─ panels-shown/<名字>.json    每个面板最后一份能显示的样子；文件坏了照它显示，伙伴看不到
└─ loci.sqlite
```

组件和语音模型不在这里，在 `~/Library/Application Support/Loci/`。

- 划线按资料分文件，放在资料之外：资料可以重新取回，划线不受影响；删除资料时划线一起进入撤销区。
- 一条划线：定位符、划线的原文、你的想法、问答（问题、回答、时间）、时间。修改和删除也是追加一行。
- 一门课程用 UUIDv7 作 id，课时用课程内稳定的短 ID。改写课文后，目录、读过的标记和划线继续沿用该 ID。课程资料留在课程的链接列表，仓库链接固定到提交。每门课程有一条对话，沿用 agent 会话和对话副本。课程和它的划线一起进入撤销区，对话随课程恢复。废纸篓成功接收课程后，才清理随课对话。
- 重开课程时，应用从保存的阶段、课程目录和尚待处理的操作恢复已发起的写课任务。
- 资料用 UUIDv7 作 id。文件夹名带一个可读的短名，方便人和 agent 浏览；以文件里的 id 为准，改名不破坏引用。
- 资料的种类：文章、论文、视频、音频。新种类只加一种阅读器和一种定位方式。

### 面板文件

`agent/panels/<名字>.json` 分三层，格式见 `loci help`：

- **形状归伙伴**：标题、来源、`follow`、刷新频率、分几段、每段用哪种行、条目段能不能加（`adds`）和勾（`checks`）。伙伴整份保存（`loci panel save`、刷新）时写它。
- **条目各有主人**：条目段里每一条有稳定 ID 和 `by`（`you` 或伙伴）。你在界面上的每次改动是一条 `EditPanel`，伙伴主动记一条是 `loci panel add`；两种都经面板管家读最新文件、改、校验、写回，和刷新排队。
- **你的态度挂在条目上**：`pinned`、`note` 是你的；伙伴只能在它自己的条目上写 `why`。

伙伴整份保存时，以当前文件为准合并：你的条目缺了放回原处，文字和主人还原；所有条目的置顶、备注照旧，勾上的不会被取消；伙伴写成「你的」新条目丢掉；你最近删掉的条目（每个面板最多记 50 条、7 天）不会被伙伴的旧副本带回来；删掉含你条目的段落就拒绝保存。伙伴一条条改时不能删你的条目、不能改你的字。盯着外面的面板（`list` 行）没有主人，你对一行的置顶、不想再看和备注存在 `panels.json`，按链接（没有就按标题）认，刷新时告诉伙伴哪些不想再看。

### 定位符

划线、引用、阅读位置，全部用同一种定位符：

```
loci://library/<id>#t=204.1,207.8                          音视频：起止秒
loci://library/<id>#quote=<原文>&pre=<前文>&post=<后文>     文本：引文加上下文
loci://courses/<课程 id>/<课时 id>#quote=<原文>            课时选段
loci://library/<id>#page=3&rect=…                          PDF
loci://library/<id>#path=src/vm.rs&L=12-40&rev=<sha>       代码
loci://library/<id>                                         整篇
loci://library/<id>#chapter=3&node=1.0.8&char=51&share=4231  书：第几章、章里的节点路径和字、全书万分比
```

书的位置不存页码：换字号或窗口大小后页码会变，节点路径和字不会。`share` 只给资料库显示读到百分之几。

文本用引文加上下文而不是字符偏移，原文重新抓取后还能重新对上；对不上时标成失效而不是指错地方。

### 数据库

| 表 | 内容 | 来源 |
|---|---|---|
| `item` · `note` | 资料、划线的镜像，用来查询 | 文件 |
| `course` · `course_lesson` | 课程与课时目录的镜像，包含正文是否可读 | 文件 |
| `search` · `search_owner` | 全文索引 | 可重建 |
| `reading_state` | 每份资料的位置与读完标记 | 数据库 |
| `session` · `message` | agent 会话与消息，只追加 | 数据库 |
| `event` | 伙伴对话上下文用到的资料库事件 | 数据库 |
| `review` | 每日回顾做过哪天 | 数据库 |
| `job` | 媒体任务的阶段与进度 | 数据库 |

先不做。只保留两个不花成本的习惯：每个实体有全局唯一的 id，每行有修改时间。

### 界面

资料库顶部是链接框和画廊、列表的切换，所选视图记在这台 Mac 上。画廊列数随窗口宽度增减。有任务时底部浮着任务胶囊。

内置浏览器的地址栏右侧和网页浮层的顶栏是同一个资料库按钮，认出当前页面和它链着的视频、论文里有哪些能存，行为见 H-S7。

```
资料库                                     视频                                  
┌────────┐ ┌────────┐ ┌────────┐        ┌───────────────────────┬─────────────┐
│ 缩略图  │ │░▕方▏░  │ │ ▒▒▒▒▒▒ │        │                       │ 文稿·对话·划线 │
│▔▔▔▔▔▔  │ │░▕封▏░  │ │识别 42%│        │       大播放器          │ 12:01 The…   │
└────────┘ └────────┘ └━━━─────┘        │                       │▌12:04 then…  │
标题两行     标题        标题               │ ━━●━━◆━━━◆━━  12:04   │ 12:09 …      │
42:10·频道  1:12:03     23:40·频道         └───────────────────────┴─────────────┘
```

- 卡片：封面一样大（16:10），一行一行排，每行对齐；播客的方图居中，两边是它自己颜色的模糊底。封面底部的细琥珀线是进度；时长和站点用等宽；不加种类标签，靠封面里的样子和来源行的图标区分。没有图片的资料是纸面封面：站点首字的印章和站点名，不重复标题。
- 链接框是一条胶囊：左边链接图标（框里是链接时变琥珀），中间按页面变的提示，右边「本地文件」。它跟资料一起滚动。资料库和各分类为空时，顶部控件照样可用。
- 网址认不出是什么的链接，提取正文之前先问 yt-dlp（不用它的通用解析器）：它认得的网站上有视频或音频，就当视频或播客；要登录就等登录；否则按文章读。下载用解析时存下的 `info.json`，不再读第二遍网页，地址过期时才重新读。
- 视频和播客链接收进来之前先过导入卡片：卡片用 `yt-dlp -J` 读一次，读到的 JSON 和封面交给新资料的任务，解析阶段直接用它。任务按 `import.json` 排阶段：保存到本地是解析 → 识别 → 下载 → 翻译 → 章节，识别要的音频先单独下，选了仅音频就直接收下这份；在线看没有下载，识别用的音频识别完就删。有网站字幕且选用时不识别。
- 资料右键：重命名、换封面、释放空间或保存到本地（视频和播客）、拷贝链接、删除。重命名把标题就地变成输入框。⌘ 点击、Shift 点击多选，选中的卡片描琥珀边，列表行用琥珀底色。
- 进行中的卡片封面模糊、边框琥珀流光，封面底部是阶段、百分比和一条细阶段尺，卡片和别的一样高；悬停出现暂停或继续、取消（玻璃小圆钮）。暂停去色，阶段尺当前段斜纹；等你处理时封面中间是按钮。新收进来的资料从上方落进画廊。流光和阶段尺的光用 `TimelineView` 驱动。
- 任务胶囊：进度环里是当前任务的小封面，旁边是标题和阶段尺，其余任务的小封面叠在右边；点开向上展开成任务列表。伙伴用 `loci save` 收东西时胶囊换成「正在收进资料库 n / m · 停止」，窗口四边亮起流动的琥珀光，不挡点击。
- 暂停保留做好的部分：下载留着 `.part`，继续时 `--continue` 接着下；翻译一批（60 句）一批存在工作目录里；退出再开，暂停的还是暂停。取消就是删除这份资料，可以撤销。
- 还在准备的视频，资料页的播放区是模糊封面加流光边框，中间是百分比和已下载大小，下面是阶段尺。资料页的右栏默认收起，记住上次的开关。
- 设置 › 媒体最上面是存储：总量、按视频、播客、语音模型分色的一条，下面是视频和播客的列表，可以释放空间或保存；语音模型在「语音识别」列表里删除，在用的不能删。释放空间删掉媒体文件，把这份资料改成在线看，文稿、译文、划线、章节、重点都留着。
- 删除不问：资料文件夹和划线先挪到 `~/Loci/.deleted/<id>/`，底部浮出「已删除 · 撤销」，⌘Z 也能撤销。下一次删除、退出应用或下次启动时才丢进废纸篓，同时删掉数据库里的陪读对话、事件和任务；所以只能撤销最近一次删除。
- 重置（`DataReset`）问过一次就做：先停下伙伴、任务和对文件夹的监听，把整个数据文件夹（连数据库）移进废纸篓，只带回 `settings.json`，再在空文件夹上启动，窗口整个重建。远程只能看不能重置别的 Mac。
- 文章用 TextKit 2 阅读器，标题下一行：作者 · 站点 · 日期 · 原文链接；收它时写了为什么，再下一行用衬线斜体。
- 文稿里选中句子弹出同一个「划线 / 问问这段」工具条；问伙伴时右栏切到对话。
- 快捷键：空格播放暂停，← → 跳五秒，< > 调速。

### 技术方案

```
这台 Mac                                            另一台 Mac
 LociUI ── 当前 Host ─┬─ LocalHost                     LocalHost ── Gateway
                      └─ RemoteHost ── 加密会话 ──┐            │
                           控制连接 / 数据连接      └─▶ alma-relay ◀── 外连注册
 Machines：名单、附近的 Mac、配对、邀请、切换
```

| 层 | 内容 |
|---|---|
| `LociModel` | 界面看得到的契约：`Machine`（id 是公钥指纹、名字、机型决定图标）、`Machines` 协议（名单与状态的流、附近的 Mac、配对的步骤、邀请、处理配对请求、移除、打开一台 Mac 得到它的 `Host`）、连接状态。命令和订阅的线路注册表：每个 `Command` 和 `Subscription` 都要登记，架构检查拦住漏登记的 |
| `LociRemote` | alma-relay 的 agent 端（`/agent?th=`、register、协议 3 的帧与按 stream 的流量控制、4000 不循环重连）与客户端（`/c/<token>/__loci__`）；Noise_IK_25519_ChaChaPoly_SHA256，配对用同一个握手加 PSK（IKpsk2），用官方测试向量验证；帧格式；Bonjour 广播与发现；邀请链接的编码。只用 CryptoKit、Network 里现成的原语 |
| `LociStore` | 配对名单与客户端缓存的文件（按 Mac 分开），磁盘仍只归 Store；设备私钥放钥匙串 |
| `LociHost` | `Gateway`：把远程请求交给 `LocalHost`，主机只接受 `/__loci__`，其他一律拒绝；`RemoteHost`：实现 `Host`，命令在一条连接上并发、订阅先发整值再发 JSON 增量、断线自动重连、看过的值落盘供离线读；`MachinesService` 实现 `Machines` |
| `LociUI` | 当前 Mac 的切换：换掉界面背后的 `Host`，每台 Mac 各自记住上次的页面；侧边栏底部、菜单、设置 › 远程、添加 Mac、配对与邀请弹层、离线态 |
| `Loci` | 启动时接上 `Machines`；官方中继的地址和注册密钥从构建注入的值读 |

- **两条连接。** 控制连接只走命令、订阅和增量；封面、PDF、图片、媒体片段走数据连接。协议 3 的流量控制按 stream 算，下载 PDF 时对话不会卡。
- **媒体播放。** 远程时 AVPlayer 用自定义 scheme，经 `AVAssetResourceLoaderDelegate` 把区间请求变成数据连接上的区间读取。
- **路径不过边界。** `ImportMediaFile.file`、`Playback.url`、`dataLocation()` 这类带本机路径的值，在类型上过不了边界（上传句柄、定位符、只在本机有效的类型）。
- **主机不睡。** 有已配对的 Mac 且接着电源时，用电源断言阻止空闲睡眠，不再起 `caffeinate`。
- **路由。** 每台 Mac 的路由令牌由自己的私钥派生，中继只存它的 sha256；名单里的 Mac 才知道令牌和公钥。移除一台 Mac 后它的握手被拒，已建立的连接立即断开。
