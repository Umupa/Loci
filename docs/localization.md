# 设置页语言

Loci 的工作区保持英文，只有设置页支持简体中文。可在“Settings → 通用 → 设置页语言”中选择简体中文、英文或跟随系统。切换立即生效，选择会保存在本机并同步到其他窗口的设置页，不会清空草稿。

中文覆盖设置导航、各设置分区及从设置页打开的弹窗。工作区的对话、输入框、模型与权限选择、菜单、通知、笔记和画布均保留英文。用户内容、产品名、模型名、路径和协议标识保留原文。

系统语言按偏好顺序匹配英文或中文，其他语言回退到英文；中文地区变体目前统一使用简体中文。

## 学习语言

学习语言与设置页语言是两回事：它决定导师写作用的语言（回复、课程与章节标题、课程简介、导读、笔记、日报），不改变界面文案。在“Settings → 通用 → 学习语言”中选择“跟随我的消息”、简体中文或 English；每位导师可在自己的设置里改成别的语言，或回到“默认”。终端里分别用 `loci settings set learningLanguage zh-CN` 与 `loci mentors update <id> --language en`（`default` 回到设置页的选择）。

选择会写进导师的 `mentor.json`（`language`），并由 `src/features/agents/model/learningLanguage.ts` 在每一轮对话里以 `<language>` 块告诉导师，所以修改立即生效，也会盖过旧导师 Soul 里“用学习者的语言回复”的规则。“跟随我的消息”不发送这个块。一手资料保持原文，导师不得把译文存成资料；资料的译文旁存，见 [learning.md](learning.md) 的“用学习语言读一手资料”。

## 添加文案

- `src/shared/i18n/zh-CN.json` 维护设置页的英文原文与简体中文映射，缺失译文时回退到英文。
- 设置页专用组件使用 `useLocale()` 订阅偏好，以 `t()` 获取文案。设置搜索索引也使用该偏好。
- 设置页与设置导航分别由 `SettingsLanguage` 包裹。共用组件通过 `useUiText()` 获取所在区域的语言和翻译函数，默认英文。React portal 中的弹窗继承上下文，弹窗元素单独声明 `lang`。
- 界面主文档固定为英文，只有设置区域声明对应的 `lang`。不要通过全局状态临时切换语言来渲染共用组件。
- 通知类别、模型参数等共用数据保留英文原值，在设置页的展示位置翻译。独立于 React 的共用文案函数接受显式语言参数，默认英文。
- 动态内容使用完整句子和占位符，不按英语词序拼接中文，不把用户输入当作翻译键。

设置说明以准确、自然为先。同一术语保持一致，权限和删除确认完整说明后果；不为追求文采省略条件或生效时间。

## 验证

`src/shared/i18n/locale.test.ts` 检查偏好保存、多窗口同步、占位符、中文搜索、区域隔离及 portal 内的共用控件。既有组件测试验证工作区英文行为，设置页测试验证中文快捷键名称不会改变内部命令标识。

运行 `npm run dev`，打开 `/scripts/acceptance/i18n.html` 可同时查看设置页和英文会话区域。该预览使用模拟数据，不访问用户数据库或启动智能体。切换语言时，应只有设置区域变化，工作区文案和草稿保持不变。
