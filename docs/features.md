# 功能地图

从用户的角度说 Loci 有什么、每样东西叫什么、怎样算做对。人和 agent 都用这里的词；代码里的类型名与这些词一一对应。新功能先在这里写场景，再写代码。

## 词汇

| 词 | 意思 | 代码里 |
|---|---|---|
| 导师 | 一个长期存在的 agent，负责一个领域或一种风格；有 Soul 和 Memory，可以带多门课 | `Mentor` |
| 课程 | 一位导师为一个学习目标写的一组课；侧边栏的主角。现在一位导师只有一门，数据改成一对多之前，课程就是导师的目录 | `Catalog` |
| 目录 | 一位导师的章和课 | `Catalog` |
| 章 | 目录里的一组课，只是分组 | `Catalog.Chapter` |
| 课 | 导师写的一篇讲解；用导师起的短名（slug）标识，也是课文的文件名 | `Lesson` |
| 出处 | 课文开头列出的资料或待取回的链接 | `Lesson.Source` |
| 引用 | 一课指向一份资料，或资料里的某一处 | `Citation` |
| 资料库 | 所有资料的家，和导师并列 | `Library` |
| 资料 | 一份别人写的材料：文章、论文、视频、音频、仓库。不属于任何导师 | `Item` |
| 文稿 | 视频或音频转录出的文字，一句一句带时间 | `Transcript` |
| 重点 | 导师替一份视频或音频挑出的片段 | `Outline.Highlight` |
| 章节 | 视频或音频按时间分的段落，平台自带或导师分 | `Outline.Chapter` |
| 译文 | 文稿的另一种语言，一句对一句 | `Translation` |
| 任务 | 把一份资料变得可读的各个阶段：解析、提取正文、下载、识别、翻译、章节与重点 | `Job` |
| 组件 | 应用调用但不自带的程序：yt-dlp、FFmpeg、QuickJS | `Component` |
| 语音模型 | 本机识别语音用的 Whisper 模型，七个型号按需下载 | `SpeechModel` |
| 内置浏览器 | 应用里的网页，用来登录网站、找视频、把正文加入资料库 | `Browser` |
| 陪读 | 打开一份资料时选一位导师来回答问题，不产生绑定 | — |
| 划线 | 读的时候留下的一条东西：一个位置，加上可有可无的想法和问答。英文界面叫 Highlights | `Note` |
| 定位符 | 指向内容里某一处的地址：一句话、一段时间、几行代码、PDF 的一块 | `Locator` |
| 面板 | 阅读器右侧的栏：对话、划线；视频与播客另有文稿、重点 | `Panel` |
| 开始页 | 只有一个输入框的页面：写一句话建导师，粘链接或拖文件加资料 | `StartPage` |
| Host | 界面背后那套命令；本机和远程是同一套 | `Host` |

## 场景

每条场景有编号，派活和验收时引用编号。写法：前提、动作、看得到的结果。

### α1：骨架与数据

| 编号 | 场景 |
|---|---|
| α1-S1 | 第一次打开应用，看到开始页，只有一个输入框。 |
| α1-S2 | 在开始页写一句话并回车，侧边栏多出一位导师，并打开它；它的目录是空的。 |
| α1-S3 | 把一个文本文件拖到开始页，资料库多出一份资料，并打开它，能读到全文。 |
| α1-S4 | 退出再打开应用，回到上次打开的那位导师或那份资料。 |
| α1-S5 | 应用开着时，在访达里改一位导师文件夹下的 `mentor.json` 里的名字，一秒内侧边栏跟着变。 |
| α1-S6 | 手写一课并在出处里引用一份资料：从这一课看得到这份资料，从这份资料看得到这一课。 |
| α1-S7 | 删掉数据库文件再打开应用，导师、资料、课和引用关系都还在。 |
| α1-S8 | 按 ⌘, 打开设置窗口。 |
| α1-S9 | 系统切换亮暗，应用跟着变，暖白和暖黑两套颜色都没有看不清的文字。 |
| α1-S10 | 从点开应用到能在开始页打字，不超过 0.5 秒。 |

### α2：导师与读课

| 编号 | 场景 |
|---|---|
| α2-S1 | 在开始页写「想学 Kubernetes 调度」并回车，几分钟内导师页出现目录，随后第一课可读。 |
| α2-S2 | 目录还没写出时，导师页显示导师正在做什么，而不是空白。 |
| α2-S3 | 读完一课到底，它标为已读；点「下一课」打开下一课，未写的课可以请导师写。 |
| α2-S4 | 在课文里选中一句话提问，回答在右栏对话里流式出现，答完存进这条划线（2026-11-17 改，见 UI-S6）。 |
| α2-S5 | 选中一句话只划线、写一句想法，退出再打开，划线和想法都还在。 |
| α2-S6 | 和导师对话：回复流式出现；导师运行命令不再询问，一律 Full access（2026-11-17 改）。 |
| α2-S7 | 对话进行中按停止，导师停下，之后还能接着聊。 |
| α2-S8 | 退出再打开应用，对话记录都还在。 |
| α2-S9 | 导师修订了一课，读者看得到这一课改过、改了哪里。 |
| α2-S10 | 设置里看到本机装了哪些 agent CLI；新导师可以选 Pi 或 Grok。 |
| α2-S11 | 长课文（两万字）滚动不卡，再次打开回到上次读到的位置。 |

### 界面改版（2026-11-17）

设计稿是 `output/sketches/redesign.html`（不提交），规则见 design.md 的「设计」。

| 编号 | 场景 |
|---|---|
| UI-S1 | 窗口没有工具栏；侧边栏是悬浮的玻璃面板，红绿灯在它里面。 |
| UI-S2 | 侧边栏依次是开始、课程、资料库、导师、设置。点课程打开它当前的课；悬停出现折叠箭头，展开后列出各课和读过、当前、未读、未写四种状态。 |
| UI-S3 | 课文页没有目录页、没有上一课和下一课；标题离窗口上沿不超过 40。 |
| UI-S4 | 右栏顶部一行：居中的小分段「对话 / 划线」，最右是收起按钮。收起后窗口右上角留一个玻璃按钮重新打开。 |
| UI-S5 | 选中一句话，弹出「划线 / 问导师」。点划线立刻生效，原地出现想法输入框，不写直接回车或点空白就收起。 |
| UI-S6 | 点问导师，右栏切到对话，引文出现在输入框上方；发出后回答在对话里流式出现，有思考和工具；答完这条问答存进那条划线。 |
| UI-S7 | 点划线页的一条或对话里的引文，正文滚到原处并闪一下。 |
| UI-S8 | 输入框下方能切换 agent、模型、思考程度，看到上下文用量；报不出用量或思考程度的 agent 不显示对应控件。 |
| UI-S9 | 导师页：头像、名字、agent 与模型；工作时显示在做什么；它的课程像书架上的书；Memory 列出 `memory/` 下的文件，Soul 显示 `SOUL.md`，导师改了文件页面跟着变。 |
| UI-S10 | 设置在侧边栏里：通用（外观、语言、数据文件夹）和 Agent（每家的图标、版本、是否可用、默认 agent、各家默认模型）；⌘, 打开这一节。没有权限设置，导师一律 Full access。 |

### α3 与 α4：资料库（2026-11-18）

文章、视频、播客一起做完再交付。参考 Vimpo 的取回和播放，不做它的工作室、广告拦截、多资料库和 API Key。

| 编号 | 场景 |
|---|---|
| L-S1 | 在资料库按 ⌘V 或在开始页粘一个文章链接，5 秒内打开正文；图片存在本机，断网也能读。 |
| L-S2 | 粘 arXiv 或 PDF 链接，资料种类是论文，用 PDF 阅读。 |
| L-S3 | 粘 YouTube 或 B 站链接，卡片立即出现并显示进度；3 秒内能在线播放，下载在后台进行。 |
| L-S4 | 粘播客单集链接（Apple Podcasts、小宇宙、音频直链），能播放，卡片有封面。 |
| L-S5 | 视频有平台字幕时直接出文稿；没有时显示「识别 n%」，识别出的句子陆续出现在文稿里。 |
| L-S6 | 播放时文稿当前句高亮并跟着滚动；手动滚动后停止跟随，出现「回到播放处」；点一句就从那里播放。 |
| L-S7 | 在文稿里选中几句划线或问导师，定位符精确到秒；从划线或课文引用点回来，跳到那一秒播放。 |
| L-S8 | 打开任意资料，右栏对话顶部选一位导师陪读，中途可以换，之前的问答还在，每条标着是谁答的。 |
| L-S9 | 第一次需要语音模型或组件时，就在那张卡片上提示下载，不用先去设置里找。 |
| L-S10 | 下载或识别到一半退出应用，再打开会接着做。 |
| L-S11 | 取回失败时卡片说明原因，并给一个能解决的按钮：更新 yt-dlp、选登录过的浏览器、重试。 |
| L-S12 | 文稿切换原文、对照、译文；重点标在进度条上，也在文稿里标出。 |
| L-S13 | 资料库卡片显示封面、时长或站点，以及观看或阅读进度。 |
| L-S14 | 设置里的「媒体」一节列出 yt-dlp、FFmpeg、QuickJS 的版本和来源，可更新、可重新检测；Whisper 七个模型可下载、可删除、可选默认。 |
| L-S15 | 在内置浏览器里打开一个网址并登录；页面有视频时出现「下载视频」，点了进资料库；有正文时可以「加入资料库」。 |
| L-S16 | 需要登录的视频，在内置浏览器登录过或设置里选了浏览器登录信息后能取回。 |
