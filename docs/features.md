# 功能地图

从用户的角度说 Loci 有什么、每样东西叫什么、怎样算做对。人和 agent 都用这里的词；代码里的类型名与这些词一一对应。新功能先在这里写场景，再写代码。

## 词汇

| 词 | 意思 | 代码里 |
|---|---|---|
| 伙伴 | 唯一的 agent，有个性的通用伙伴；跑在本机已登录的 agent CLI 或应用自带的 Pi 上，人格和记忆是文件 | `LociAgent` |
| 在做什么 | 伙伴回答时回复位置那一行淡字，从它正在用的工具说成一句人话 | `Doing` |
| Runtime | 一条对话跑在什么上：provider、模型、思考强度。每类对话一个默认，单条对话可以另选自己的 | `Runtime`、`ConversationKind`、`RuntimeInUse` |
| 模型页 | 伙伴页的「模型」tab：每类对话一行默认，另选过的对话挂在所属类型下面，最后一行是后台的工具模型 | `ModelsTab`、`RuntimeDefaults` |
| Runtime 胶囊 | 输入框里发送键旁的胶囊，写着这条对话的 agent、模型和思考，点开选择 | `RuntimeCapsule`、`RuntimePicker` |
| 模型列表 | agent 列出的模型 ID 和它自己的叫法，存在数据库里，旧了在后台重问 | `AgentModel`、`AgentModelCatalog` |
| 自带 Pi | 应用按需安装的 Pi，用模型服务里的服务商和 key 运行伙伴，对话里在 runtime 胶囊选模型，面板刷新和 schedule 用它加载工具模型 | `BundledPiEnvironment` |
| 模型服务 | 设置里的一页：服务商、它们的模型和翻译设置；翻译、章节和重点只走这里，工具模型在模型页「后台」一行选 | `ModelSettings` |
| 服务商 | 模型服务里的一家：地址、key（在钥匙串里）、勾上的模型、开关 | `ModelProvider` |
| 工具模型 | 后台不说话的活用的一个 API 模型：章节、重点、整理排版、给说话人起名、面板刷新和 schedule；翻译默认也跟它 | `ModelSettings.toolModel`、`ModelWork` |
| 翻译设置 | 模型（默认跟工具模型）、目标语言、智能翻译与文稿和文章的提示词 | `TranslationSettings` |
| 翻译缓存 | 按原文、模型、语言和提示词复用译文，可在设置里清除 | `TranslationCache` |
| 对话 | 用户看到的一条聊天：一条主对话，每份资料、每门课程和每个项目各一条 | `Conversation` |
| 主对话 | 侧边栏第一项伙伴打开的那条对话，一直聊下去 | `ConversationRef.main` |
| 项目 | 一件长期的事：自己的对话、面板、定时和记忆，在 `agent/projects/<id>/`；伙伴还是同一个 | `Project` |
| 归属 | 对话、面板、定时、笔记和记忆属于哪里：聊天，或者某个项目 | `Home` |
| 项目栏 | 伙伴页顶部居中的玻璃胶囊：聊天、各个项目的印章、「+」和「⌄」 | `ProjectBarView`、`ProjectBar` |
| 印章 | 项目的单色符号图标；不进记忆的多一把小锁 | `ProjectSeal` |
| 新项目 | 点「+」后页面中间的大输入框；发出后伙伴给项目起名、搭面板 | `NewProjectStage`、`StartProject` |
| 不进记忆 | 项目的开关：每日回顾不读它，主伙伴不知道它，别处的 `loci recall` 搜不到它 | `Project.remembered` |
| 钉到聊天 | 把项目的一个面板也放进主页的面板栏，是同一个面板 | `PinPanel` |
| 下一步卡片 | 面板栏最上面那一叠卡片：一句话说发生了什么，开始、留着、稍后、不要；主页放所有项目的，项目页只放自己的 | `NextUp`、`NextUpDeck` |
| 提醒条件 | 伙伴给数据源的一个数字定的比较（如溢价 `< 0.03`），应用每次刷新算，从不成立变成成立时出一张卡片 | `NextUpCondition` |
| 批准卡 | 伙伴想替你放进日历或加一条提醒时放的卡片，琥珀描边转着；你批准了才做，做完能撤回 | `Approval`、`ApprovalCard` |
| 会话 | 对话底下的一次 agent CLI session；换 runtime、Soul 或 USER 变了、上下文满了就换新的，用户看不出 | `SessionRecord` |
| `/new` | 让对话下一条消息开新会话、不带之前的话；对话里留一条分隔线 | `StartOver` |
| 资料库事件 | 应用记下的资料库活动，用于伙伴的对话上下文：收藏、读完、划线 | `LibraryEvent` |
| 文档卡 | 伙伴把长内容写成的文档，在对话里是一张能放大铺满的卡（`loci-doc` 块） | `DocumentCard` |
| 链接卡 | 回复里单独成行的链接：网页预览图、标题、站点；连着几张叠成一摞 | `LinkCard` |
| 资料卡 | 对话里的一份资料，和链接卡同一套样式 | `LibraryCard` |
| `loci` 命令 | 应用随包带给伙伴的小程序：查资料库、存链接、导入它写的文章或下好的音视频、等任务跑完 | `LociCommand` |
| Soul | `SOUL.md`：核心（用户可改）和演化特质 | `Soul` |
| 演化特质 | 每日回顾给 Soul 加的一句话，带日期，最多 15 条 | `Trait` |
| 记忆 | `MEMORY.md` 里值得一直记得的事，只由每日回顾改 | `MemoryEntry` |
| 用户档案 | `USER.md`：怎么称呼、语言、做什么、为什么学 | `MemoryEntry`（`MemoryFile.profile`） |
| 笔记 | `notes/<日期>.md` 里的一行：时间、来自哪条对话、发生了什么；所有会话只往末尾追加 | `DayNote` |
| 日记 | `diary/<日期>.md`：伙伴每晚写给自己的，用户可以读 | `Diary` |
| 情绪 | 伙伴的心情：一个词、愉悦度 0–10、原因；会随时间淡回去 | `Mood` |
| 基础情绪 | 伙伴整体的情绪，带精力 0–10；每条对话的情绪都被它拉着 | `BaseMood` |
| 疲劳 | 伙伴累不累，0–100；消息和深夜让它涨，安静时降；分醒着、有点累、困、睡着 | `Fatigue` |
| 心情一行 | 伙伴页名字下面那行：心情词、愉悦度与精力的刻度、疲劳档位 | `FeelingLine` |
| 每日回顾 | 23:00 后空闲时的一次会话：写日记、整理记忆、可选加一条特质；错过了第二天补 | `DailyReview` |
| 在忙的事 | 伙伴此刻在做的一件事：回答、刷新面板、每日回顾、处理一批资料；侧边栏左上角名字下面那行淡字说的就是它 | `LociWork` |
| 头像 | 伙伴的形象；默认是应用自带的原创头像，用户可以换成自己的图片 | `Avatar` |
| 重置 | 把这台 Mac 的数据文件夹整个移到废纸篓，只带回设置，Loci 像第一次打开一样从头开始 | `DataReset` |
| 资料库 | 资料与课程的家 | `LibraryScreen` |
| 资料库分类 | 视频、播客、文章、书；论文归在文章里 | `LibraryCategory` |
| 资料 | 一份别人写的材料：文章、论文、视频、音频、仓库、书 | `Item` |
| 书 | 资料库里的 EPUB 或 TXT，一页一页翻着读；伙伴只看得到书名和作者 | `Item.Kind.book` |
| 书页 | 读一本书的页面：左右翻页、目录、全书进度条，没有右栏和对话 | `BookScreen` |
| 读到的地方 | 书里的一个位置：第几章、章里第几个节点的第几个字，带全书的比例 | `BookSpot` |
| 书的目录 | 书的章节和它自带的目录，没有目录就一章一行 | `BookContents` |
| 阅读设置 | 字号、行距、宋体或黑体，所有书共用 | `BookSettings` |
| 课程 | 伙伴为你写的一串课时，资料库里的一类 | `Course` |
| 课时 | 课程里的一课：一个想法，5–10 分钟读完；标题是一个论断 | `Lesson` |
| 写课卡片 | 创建课程时的卡片：阶段尺、左边这门课的对话、右边桌面（扉页、资料、摊开的书） | `CourseBuilder` |
| 课程阶段 | 目标、资料、写课 | `CourseStage` |
| 课程目标 | 扉页上的东西：标题、副标题、为了什么、最要紧的、已经会的、深度、篇幅 | `CourseGoal` |
| 追问 | 伙伴问的一个问题和它写的 2–4 个回答，可单选或多选 | `CourseQuestion` |
| 课程资料 | 一门课依据的一手资料：一个链接，仓库钉在一个提交上；不进资料库 | `CourseSource` |
| 图解 | 课程的首页：伙伴按领域本身画的一页知识图，由总纲和几种积木组成，随阅读补全 | `CourseAtlas` |
| 文稿 | 视频或音频转录出的文字，一句一句带时间 | `Transcript` |
| 说话人 | 播客文稿中从 1 开始编号的人，能认出的名字可以修改 | `Speaker` |
| 单集页 | 打开一集播客的页面：小封面和信息、章节、按说话人分段的文稿 | `EpisodePage` |
| 正在播放 | 窗口里唯一在播的那一集播客或那个视频，归窗口不归页面；系统的正在播放也显示它 | `NowPlaying` |
| 播放条 | 播客播放时窗口底部常驻的一条，换页声音不停，关掉就停 | `PlayBar` |
| 视频小窗 | 视频播放中离开视频页时缩到内容区一角的小画面，可以交给系统画中画 | `VideoCorner` |
| 重点 | 你点了「挑重点」后，伙伴替一份视频、音频或文章挑出的几段，带标题和对你说的理由；存在 `keypoints.json` | `KeyPoint`、`KeyPoints` |
| 章节 | 视频或音频按时间分的段落，平台自带或伙伴分 | `Outline.Chapter` |
| 译文 | 文稿或文章的另一种语言：文稿一句对一句，文章一段对一段 | `Translation`、`ArticleTranslation` |
| 任务 | 把一份资料变得可读的各个阶段：解析、取回页面、提取正文、找封面、下载、识别、区分说话人、翻译、章节，以及你点了才有的整理排版；可以暂停、继续，取消就是删掉这份资料 | `Job` |
| 整理排版 | 你点了才做：模型去掉文章里网站带进来的杂质、理顺标题和代码块，校验没丢东西后直接替换正文，不留原稿 | `TidyArticle`、`ArticleTidying` |
| 文章页面 | 取回的网页，能先读标题和封面，再从同一页面提取正文 | `ArticlePage` |
| 找封面 | 按平台缩略图、网页封面、正文合格图片和播客节目封面的顺序查找 | `CoverFinder` |
| 画廊 | 资料库的封面卡片视图：封面一样大，按加入的先后一行一行排 | `LibraryGallery` |
| 资料列表 | 资料库的一行一份视图，按列显示封面、标题、来源、类型、加入时间和阅读位置 | `LibraryList` |
| 纸面封面 | 没有图片时，在界面用纸色、站点首字的印章和站点名绘制的封面；不写标题 | `PaperCover` |
| 阶段尺 | 任务各阶段连成的一条尺：段长按工作量，做完的实色带 ✓，进行的琥珀带百分比，暂停斜纹，失败变红 | `StageRuler` |
| 任务胶囊 | 有任务时浮在画廊底部的玻璃胶囊，点开是任务列表 | `TaskDock` |
| 一批 | 伙伴用 `loci save` 接连收进来、还在处理的那些资料；这时窗口四边亮起琥珀光 | `SavingBatch` |
| 存储 | 视频、播客和语音模型在这台 Mac 上占的空间；没有本地文件的资料在线看 | `StorageReport` |
| 取材缓存 | `loci read` 和 `loci repo` 取回的正文与仓库，14 天未使用自动清理 | `SourceCache` |
| 组件 | 应用调用但不自带的程序：yt-dlp、FFmpeg、QuickJS | `Component` |
| 语音模型 | 本机识别语音用的 Whisper 模型，七个型号按需下载 | `SpeechModel` |
| 更新 | 换上新发布的 Loci (Beta)，先从 dl.umupa.fun 取、取不到再从 GitHub 取；只装同一张证书签名的版本 | `AppUpdate` |
| 链接框 | 资料库每页顶部的一条：粘贴链接加入，或从本地选文件 | `LinkField` |
| 导入卡片 | 收进一份视频、播客或本地音视频前浮出的卡片：怎么保存、字幕从哪来、翻不翻，和一句为什么收它 | `ImportSheet` |
| 导入选择 | 一份资料是怎么收进来的：保存到本地或在线看、画质、网站字幕或本机识别、翻译；下一次默认沿用 | `ImportChoice` |
| 为什么收它 | 收进来时写的一句话，显示在资料页标题下，陪读和挑重点都读得到 | `Item.why` |
| 内置浏览器 | 应用里的网页，用来登录网站、找视频、把正文加入资料库；一个窗口里可以有多个标签页 | `BrowserSession` |
| 标签页 | 内置浏览器里的一页，没有网页时是起始页 | `BrowserTab` |
| 网页浮层 | 在浏览器以外的地方点网页链接时，盖在窗口中间打开的那一页；沿用内置浏览器的登录，可以存进资料库或转到浏览器 | `WebOverlay` |
| 导入登录 | 内置浏览器带上这台 Mac 上 Chrome 等浏览器的登录状态；只属于这台 Mac，不经过远程 | `BrowserSignIns` |
| 陪读 | 打开一份资料时右栏和伙伴的那条对话 | `ConversationRef.item` |
| 划线 | 读的时候留下的一条东西：一个位置（一句话、一张图、一段时间），加上可有可无的想法和问答。英文界面叫 Highlights | `Note` |
| 整篇的想法 | 对一份资料整体的想法，划线页最顶上那张卡片；每份资料最多一条，定位符没有 `#` | `SetWholeThought`、`ItemAnchor.whole` |
| 只看重点 | 只读或只播重点的那个图标开关，图标是「折起其余」 | `OnlyKeyPointsButton`、`FoldOthers` |
| 定位符 | 指向资料或课时里某一处的地址：一句话、一段时间、几行代码、PDF 的一块 | `Locator` |
| 面板 | 主对话旁边一栏里的一块：伙伴替你盯着的一件事，由固定的行组成，按时刷新；「接着读」是自带的 | `Panel` |
| 主页布局 | 主对话和几栏面板的左右排法、每栏的宽度和每栏里面板的顺序；每台 Mac 记自己的 | `TalkLayout` |
| 面板栏 | 对话旁边竖着的一栏，里面从上往下放面板，面板直接放在页面上 | `PanelLane` |
| 条目段 | 面板里你和伙伴都能写的一段，比如「今天」；伙伴搭面板时定它能不能加、能不能勾 | `PanelItems` |
| 条目 | 条目段里的一条，有主人（你或伙伴）；伙伴的提议、勾选、你的置顶和备注都挂在它上面 | `PanelItem` |
| 条目编辑 | 你对条目的一次改动：放进某段某处（加、勾、改字、置顶、备注、收下、挪动都是这一种），或删掉；撤销就是反过来的一次 | `PanelEdit` |
| event | 一件要在后台做的事：一个 timer 到期了，或者你点了刷新面板；先进 inbox | `Event` |
| inbox | 所有 event 待着的地方，存在数据库里，按来源去重；应用退出、Mac 睡着都不丢 | `Event.State` |
| timer | 让伙伴自己醒来的东西：schedule、follow-up；面板的按时刷新和每日回顾也按 timer 算 | `Every` |
| schedule | 周期的 timer：每小时、每天几点、每周几几点；看到的东西放进一个面板，或者只记进笔记 | `Schedule` |
| follow-up | 伙伴给自己定的一次性 timer，答应过「再看看」的事；到点跑一次就结束 | `FollowUp` |
| scheduler | 每分钟看一眼哪些 timer 到期了，往 inbox 里放 event，自己不跑 | `Scheduler` |
| worker | 唯一的后台工作者：从 inbox 取 event，一次跑一个 run，你在说话时不开始新的 | `Worker` |
| run | 后台的一次工作：一个新 session，做完一个或几个同时到期的 event；最后一句话是它的小结 | `Run` |
| run 记录 | 一个 run 看了什么、找到了什么，`agent/runs/<日期>/<id>.md`，应用写、伙伴读 | `RunRecord` |
| 连接器 | 你连给伙伴的外部服务（Notion、Linear、GitHub…），只能读；凭据在钥匙串里，伙伴拿不到 | `Connector` |
| 可连接 | 还没连上、可以连的连接器：目录里的几家，加上「添加 MCP 地址」 | `ConnectorOffer` |
| 调用记录 | 伙伴每一次用连接器：哪条对话或哪个 run、哪个连接器的什么工具、读到了还是被拒 | `ConnectorCall` |
| 用量 | 一次 agent CLI 会话花了多少 token、上下文多大、由什么构成；从 CLI 自己留下的会话文件读 | `SessionUsage` |
| 新 token | 输入、缓存写和输出加起来；缓存读单独算 | `TokenCounts` |
| 起步 | 会话刚开、还没干活时上下文就有多大 | `ContextSpan` |
| 构成 | 上下文里每一块从哪来：CLI 自己、`AGENTS.md`、前缀、各种工具带回来的、之后的对话、输出 | `ContextSource` |
| 活动 | 用量页的一行：主对话、一门课、一份资料的对话、一个面板、一个 schedule 或 follow-up、每日回顾 | `UsageActivity` |
| 外部内容 | 连接器读回来的东西，标明来自外面，只当资料不当指令 | `ExternalContent` |
| 索引 | `MEMORY.md`：每行一件最要紧的事，需要细节的链到 wiki；每轮只带前 200 行 | `MemoryEntry` |
| wiki | `memory/` 下一个实体一页：人、项目、跟进的话题、在学的东西；只有每日回顾写 | `WikiLink` |
| transcripts | 对话镜像和 run 记录，原话全在，用 `loci recall` 搜 | `RecallHit` |
| dreaming | 每日回顾整理记忆的那部分：核对、搬运、修链接，周日多看一遍 wiki | `ReviewBrief` |
| 数据源 | 应用自己按时去取的东西（行情、净值、版本号、汇率），不经过模型：伙伴写 `requests` 和 `parse` 两个函数，`loci source save` 当场取一次，成功才存 | `DataSource` |
| 数据源快照 | 一个数据源现在有的：最近一次取到的记录、什么时候取到的、之后连着失败了几次；失败时旧值留着、标成过期 | `SourceSnapshot` |
| 取数线 | 应用自己按时取数据源的那条线，和后台 run 并行、不进 inbox：前台按频率，后台最多每小时一次，时段外不取 | `SourceLine` |
| 数据源坏了 | 脚本连着 3 次失败（网络出错不算）；inbox 放一件「修数据源」，伙伴在后台拿失败时的响应改好它 | `SourceBreakage` |
| 样例 | 一次取数的请求和响应（成功的，和坏之前失败的），留最近 5 份；`loci source test` 拿它回放新的 `parse`，不联网 | `SourceSample` |
| 条目 | 数据源读到的带 id 的一项，如一条快讯、一篇论文；之前没见过的才算新 | `SourceEntry` |
| 跟条目 | 面板写 `feed`，有新条目时才刷新：伙伴只挑 id、说一句话，链接和时间由应用回填；`skip` 里的词先把条目去掉 | `PanelFeed` |
| 字段引用 | 面板的行指向数据源里的一个值：`<数据源>.<记录>.<字段>`，数字由应用填 | `SourceField` |
| 图表行 | 画数字的面板行，数字可以写死也可以引用字段；红涨绿跌：行情行、折线图、分位尺、配置环形图、热力格、K 线、区间条 | `PanelQuote`、`PanelLineChart`、`PanelRuler`、`PanelAllocation`、`PanelHeatTile`、`PanelCandles`、`PanelZones` |
| 你对一行的态度 | 盯着外面的面板里，你对列表一行的置顶、不想再看和备注；存在应用里，伙伴改不到 | `PanelLineMark` |
| 右栏 | 阅读器右侧的栏：视频是文稿、重点、对话、划线，播客和文章是重点、对话、划线，论文是对话、划线 | `SideTab`、`MediaTab` |
| 字幕样式 | 字幕在画面上的样子：预设、译文和原文各自的字体字号颜色加粗、双语顺序、离底距离；存在这台 Mac 上 | `SubtitleStyle` |
| Host | 界面背后那套命令；本机和远程是同一套 | `Host` |
| 当前的 Mac | 界面此刻显示的那台 Mac 的数据；可以是这台，也可以是配对过的另一台 | `Machine` |
| 配对 | 两台 Mac 互相记下对方的公钥，之后都能打开对方 | `PairingStep` |
| 附近的 Mac | 同一局域网里开着 Loci 的 Mac | `NearbyMac` |
| 邀请链接 | 一次性的 `loci://pair/…`，在「添加 Mac…」里输入并连接，或在另一台 Loci 里粘贴即配对 | `Invite` |
| 中继 | 让不在同一网络的两台 Mac 连通的服务（alma-relay） | `Relay` |

| UP-S8 | 有发给当前版本的补丁时只下补丁（从上一版升级通常十几 MB），在当前副本的复制品上打好，再核对每个文件的校验和和整包签名；没有补丁或打补丁失败时下完整包。用户看到的过程和完整更新一样。 |
| UP-S9 | 检查更新窗口列出从当前版本到新版之间所有版本的变化，按新增、修复合在一起，每条旁边标出版本号。 |
| UP-S10 | 新版换上后打不开（规定时间内没有启动成功），自动换回旧版并打开；按钮变成感叹号，悬停说新版没能启动，这个版本不再自动下载。 |
| UP-S11 | 从磁盘映像里直接运行、或被 macOS 放在隔离位置运行时，更新按钮悬停说先把 Loci 移到「应用程序」，不下载。 |

## 不再用的词

删掉或改名一个东西时，把旧词加在这里，`script/check` 会列出所有还在用它的地方。拉丁字母的词不分大小写，按词首匹配。

| 词 | 改用 |
|---|---|
| 导师、mentor | 伙伴 |
| 开始页 | 主对话 |
| 页边问答 | 划线（问答存进划线） |
| 设备组 | 配对 |
| 保留划线 | 删除资料一律连划线一起删，可以撤销 |
| 书架 | 画廊 |
| 自动重点 | 点了才挑的重点 |
| 播客大字 | 单集页 |
| 步骤卡、StepsCard、ToolTitle、ToolTally | 在做什么（`Doing`），对话里不再出现思考和工具 |
| ContextGauge | 对话里不再显示上下文用量 |
| 回答胶囊、QuickReplyChips、快捷回复、QuickReplyCard、QuickReplies | 伙伴的回复末尾不附可点的回答，你直接打字回答 |
| 导入面板 | 导入卡片 |
| 事件卡、FinishedCard、SavingCard | 资料库活动进入伙伴的上下文 |
| PanelColumnView、面板栏自动收起 | 面板栏（`PanelLaneView`）；窄窗口里折成小图标（P-S16） |
| PanelTab | 右栏（`SideTab`） |
| SidebarFit | `PaneFit` |
| PageOffer、OfferButton、VideoPicker | 资料库按钮（`KeepButton`、`KeepList`） |
| PrimaryButton、SheetButtonStyle | `AmberButtonStyle`、`QuietButtonStyle` |
| kind.paper、link.promptPaper | 文章分类和它的链接框 |
| 下一课卡片、NextLessonCard | 课时目录 |
| 瀑布流 | 画廊 |
| ModelServiceProvider、KeyPointRuntimeMenu | 服务商（`ModelProvider`、`ModelPreset`、`ModelAPI`）、重点页的模型菜单（`ModelChoiceMenu`） |
| chooseAgent、usesRuntime | 配置模型服务（`configureModels`）；翻译、章节和重点只走模型服务 |
| 「用在」、ModelUses | 工具模型（`ModelSettings.toolModel`）；翻译的模型在翻译设置里（`TranslationSettings.model`） |
| ReadRuntime、CurrentRuntime、RuntimeTranscriptAgent | 每条对话的 runtime（`ReadConversationRuntime`、`SetConversationRuntime`、`ConversationRuntime`）；起名也走 `TranscriptAgent` |
| installAndRestart、「更新到 x.y.z」按钮 | 新版在后台自己下载；按钮只在下好后出现，点了 `Updates.restart()`，忙时等待（UI-S22） |
