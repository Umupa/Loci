# 功能地图

从用户的角度说 Loci 有什么、每样东西叫什么、怎样算做对。人和 agent 都用这里的词；代码里的类型名与这些词一一对应。新功能先在这里写场景，再写代码。

## 词汇

| 词 | 意思 | 代码里 |
|---|---|---|
| Loci | 唯一的 agent，有个性的通用伙伴；跑在本机已登录的 agent CLI 上，人格和记忆是文件 | `LociAgent` |
| Runtime | Loci 跑在什么上：provider、模型、思考强度。全应用一份 | `Runtime` |
| 对话 | 用户看到的一条聊天：一条主对话，加上每份资料各一条 | `Conversation` |
| 主对话 | 侧边栏第一项 Loci 打开的那条对话，一直聊下去；资料库里发生的事也出现在这里 | `ConversationRef.main` |
| 会话 | 对话底下的一次 agent CLI session；换 runtime、Soul 或 USER 变了、上下文满了就换新的，用户看不出 | `SessionRecord` |
| `/new` | 让对话下一条消息开新会话、不带之前的话；对话里留一条分隔线 | `StartOver` |
| 事件 | 资料库里发生、出现在主对话里的事：读完一份资料、存进一份资料（带它的任务） | `WorldEvent` |
| Soul | `SOUL.md`：核心（用户可改）和演化特质 | `Soul` |
| 演化特质 | 每日回顾给 Soul 加的一句话，带日期，最多 15 条 | `Trait` |
| 记忆 | `MEMORY.md` 里值得一直记得的事，只由每日回顾改 | `MemoryEntry` |
| 用户档案 | `USER.md`：怎么称呼、语言、做什么、为什么学 | `MemoryEntry`（`MemoryFile.profile`） |
| 笔记 | `notes/<日期>.md` 里的一行：时间、来自哪条对话、发生了什么；所有会话只往末尾追加 | `DayNote` |
| 日记 | `diary/<日期>.md`：Loci 每晚写给自己的，用户可以读 | `Diary` |
| 每日回顾 | 23:00 后空闲时的一次会话：写日记、整理记忆、可选加一条特质；错过了第二天补 | `DailyReview` |
| 头像 | Loci 的形象；默认是应用自带的原创头像，用户可以换成自己的图片 | `Avatar` |
| 资料库 | 所有资料的家 | `LibraryScreen` |
| 资料 | 一份别人写的材料：文章、论文、视频、音频、仓库 | `Item` |
| 文稿 | 视频或音频转录出的文字，一句一句带时间 | `Transcript` |
| 重点 | Loci 替一份视频或音频挑出的片段 | `Outline.Highlight` |
| 章节 | 视频或音频按时间分的段落，平台自带或 Loci 分 | `Outline.Chapter` |
| 译文 | 文稿的另一种语言，一句对一句 | `Translation` |
| 任务 | 把一份资料变得可读的各个阶段：解析、提取正文、下载、识别、翻译、章节与重点 | `Job` |
| 组件 | 应用调用但不自带的程序：yt-dlp、FFmpeg、QuickJS | `Component` |
| 语音模型 | 本机识别语音用的 Whisper 模型，七个型号按需下载 | `SpeechModel` |
| 链接框 | 资料库每页顶部的一条：粘贴链接加入，或从本地选文件 | `LinkField` |
| 内置浏览器 | 应用里的网页，用来登录网站、找视频、把正文加入资料库 | `BrowserSession` |
| 陪读 | 打开一份资料时右栏和 Loci 的那条对话 | `ConversationRef.item` |
| 划线 | 读的时候留下的一条东西：一个位置，加上可有可无的想法和问答。英文界面叫 Highlights | `Note` |
| 定位符 | 指向资料里某一处的地址：一句话、一段时间、几行代码、PDF 的一块 | `Locator` |
| 面板 | 阅读器右侧的栏：对话、划线；视频与播客另有文稿、重点 | `PanelTab` |
| Host | 界面背后那套命令；本机和远程是同一套 | `Host` |
| 当前的 Mac | 界面此刻显示的那台 Mac 的数据；可以是这台，也可以是配对过的另一台 | `Machine` |
| 配对 | 两台 Mac 互相记下对方的公钥，之后都能打开对方 | `PairingStep` |
| 附近的 Mac | 同一局域网里开着 Loci 的 Mac | `NearbyMac` |
| 邀请链接 | 一次性的 `loci://pair/…`，在另一台 Loci 里粘贴即配对 | `Invite` |
| 中继 | 让不在同一网络的两台 Mac 连通的服务（alma-relay） | `Relay` |

课程这一期隐藏，写课流程重构时按新布局重做，词汇到时再加。

## 场景

每条场景有编号，派活和验收时引用编号。写法：前提、动作、看得到的结果。

### α1：骨架与数据

| 编号 | 场景 |
|---|---|
| α1-S1 | 第一次打开应用，看到和 Loci 的主对话，只有一个输入框。 |
| α1-S3 | 把一个文本文件拖进应用，资料库多出一份资料，并打开它，能读到全文。 |
| α1-S4 | 退出再打开应用，回到上次打开的那份资料。 |
| α1-S7 | 删掉数据库文件再打开应用，资料和划线都还在。 |
| α1-S8 | 按 ⌘, 打开设置窗口。 |
| α1-S9 | 系统切换亮暗，应用跟着变，暖白和暖黑两套颜色都没有看不清的文字。 |
| α1-S10 | 从点开应用到能打字，不超过 0.5 秒。 |

### α2：对话与阅读

| 编号 | 场景 |
|---|---|
| α2-S4 | 在资料里选中一句话提问，回答在右栏对话里流式出现，答完存进这条划线。 |

| α2-S7 | 对话进行中按停止，Loci 停下，之后还能接着聊。 |
| α2-S8 | 退出再打开应用，对话记录都还在。 |
| α2-S10 | 设置里看到本机装了哪些 agent CLI。 |

### Loci：agent、Soul、记忆（2026-11-18）

方案见 [agent.md](agent.md)，设计稿 `output/sketches/loci-agent.html`。

| 编号 | 场景 |
|---|---|
| L-S1 | 在主对话里说一句话，回复流式出现；退出再开，主对话都还在，续用同一个会话。 |
| L-S2 | 只输入 `/new`：对话里出现分隔线，之前的消息都还在；下一条消息开新会话，不带之前说过的话。 |
| L-S3 | 换 runtime、改 Soul、`USER.md` 变了、上下文用到 75% 或 agent 自己压缩了上下文：下一条消息开新会话，带上最近的问答接着聊，对话里看不出换过。 |
| L-S4 | 在一份资料的对话里问第一个问题，Loci 知道这是哪份资料、正文和划线在哪；选段提问答完存进那条划线；主对话和资料对话可以同时在答。 |
| L-S5 | 每条消息前带着现在的时间与时段、上次说话以来资料库里发生的事、最近在读的资料；`MEMORY.md` 和今天、昨天的笔记只在没发过或变了时再附，笔记过长只留最后一段。 |
| L-S6 | 设置里选的 runtime 是全局一份；下一轮用新的 provider、模型和思考强度。 |
| L-S7 | 23:00 后、10 分钟没说话、没有回合在跑：Loci 回顾这一天，写日记、整理 `MEMORY.md`、可选加一条特质；每天一次，错过了第二天补，什么都没发生的日子不回顾；回顾时侧边栏的小点亮着。 |
| L-S8 | Loci 页显示 Soul 核心（可编辑保存，特质不变）、特质（新的在前）、记忆（日期与出处）、`USER.md`、今天的笔记（时间与来自哪条对话）、日记、相处天数与对话数与一起读过的资料数；在访达里改这些文件，页面跟着变；删一条记忆只删那一行；格式不对的行原样显示。 |
| L-S9 | 读完一份资料、存进一份资料，主对话里在当时的位置出现一条事件；还在取回、转录的资料带着任务进度；资料删了，事件也不见。 |
| L-S10 | 换头像后各处一起变，恢复默认后回到自带头像。 |

### 界面改版（2026-11-17）

设计稿是 `output/sketches/redesign.html`（不提交），规则见 design.md 的「设计」。

| 编号 | 场景 |
|---|---|
| UI-S1 | 窗口没有工具栏；侧边栏是悬浮的玻璃面板，红绿灯在它里面。 |
| UI-S2 | 侧边栏顶部是 Loci（头像、名字，在干活时右侧琥珀小点呼吸），下面是资料库（全部、视频、播客、文章、论文、浏览器），然后是设置（通用、Agent、媒体、远程）；配对过别的 Mac 时最底下是当前 Mac 的名字（见 R-S4）。点 Loci 进主对话；已经在主对话时再点进 Loci 页面。 |
| UI-S3 | 主对话像发消息：Loci 的一条回复按空行分成几个气泡（代码、列表、表格、公式、引用各自整块），连续几个只在最后一个旁边有头像，首中尾圆角不同；用户的气泡是琥珀浅底在右边。隔一小时以上出现日期分隔。新消息上浮淡入。 |
| UI-S4 | 资料右栏顶部一行：Loci 的头像和名字，右边是小分段（文章「对话 / 划线」，视频播客「文稿 / 对话 / 划线」）和收起按钮。收起后窗口右上角留一个玻璃按钮重新打开。没有选人。 |
| UI-S5 | 选中一句话，弹出「划线 / 问 Loci」。点划线立刻生效，原地出现想法输入框，不写直接回车或点空白就收起。 |
| UI-S6 | 点问 Loci，右栏切到对话，引文出现在输入框上方；发出后回答在对话里流式出现，有思考和工具；答完这条问答存进那条划线。 |
| UI-S7 | 点划线页的一条或对话里的引文，正文滚到原处并闪一下。 |
| UI-S8 | 输入框是玻璃卡片：一行字，下面是回形针（添加文件）、runtime 胶囊（主对话写 agent · 模型 · 思考，陪读只写模型 · 思考，点开切换，全应用一份）、上下文用量和发送键。可发送时按钮亮起琥珀色，回答中换成停止键。报不出用量或思考程度的 agent 不显示对应控件。 |
| UI-S9 | Loci 页面：大头像（右下角相机按钮换图，右键恢复默认），名字，相处天数、消息数、一起读过的资料数；Soul / 记忆 / 日记三页。Soul 左边是核心可编辑，右边是长出来的特质时间线；记忆每条带日期和出处，悬停出现「忘掉」；右边是今天的笔记和来源；日记左边日期、右边衬线正文和「要记住的」。文件改了页面跟着变，解析不了的行原样显示。 |
| UI-S10 | 设置在侧边栏里：通用（外观、语言、数据文件夹、当前版本和构建号，如 `1.1.0 (412)`）和 Agent（每家的图标、版本、是否可用，Loci 用哪个，它的模型和思考程度）；⌘, 打开这一节。 |
| UI-S11 | 对话里 `$$…$$`（单行或跨行）和 `\[…\]` 排成居中的块公式，和行内公式同一套排版。 |
| UI-S12 | 连续多次工具调用折叠成一行，按动作计数（运行了 3 条命令，读了 2 个文件）；点开逐条：命令不带 shell 外壳，读取、修改、创建、删除显示文件名，汇总按删除另计，网页搜索显示查询词；运行中的那条有动效，失败的有警告。 |
| UI-S13 | 悬停一条答完的回复，下方出现复制整条的按钮；悬停代码块，右上角出现复制按钮；点后变成勾。 |
| UI-S14 | 发出新问题时对话滚到底并跟着回答走；往上滚就不再拉回，输入框上方浮出「回到最新」，生成中是跳动的点，生成后是箭头，点了回到底部并恢复跟随。 |
| UI-S15 | 输入框里 Return 和 ⌘Return 发送，Shift+Return 换行。只输入 `/new` 是重新开始：不发给 Loci，对话里出现「新对话」分隔线，之前的消息都还在，下一条消息开一个新的 agent 会话；退出再开也一样。 |
| UI-S16 | 窗口窄于 1000 时，资料页的侧边栏让位给对话；这时手动打开的侧边栏会保留，窗口变宽后侧边栏回来。 |
| UI-S17 | 主对话里，读完一份资料是一条细线胶囊（封面、「读完 · 标题」、时间）；存进资料库的东西还在取回、下载、识别时是任务卡（步骤、进度条、停下的原因），做完是一排封面卡片，点开就是那份资料。 |
| UI-S18 | Loci 的头像是一个原创角色，所有地方同一张脸；换成自己的图片后，侧边栏、对话、陪读、Loci 页面一起换。 |
| UI-S19 | Loci 用的 agent 没装或装了起不来时，对话里那一轮的结尾分别说「<agent> 没有安装在这台 Mac 上」和「已经安装，但无法启动……请检查权限设置」，中英都有。 |
| UI-S20 | 衬线里的中文用宋体、拉丁字母用 New York，全角标点后不多出空隙（Soul、日记、引文、资料标题、文章正文都一样）。系统设置里打开「减弱动态效果」后，新消息和分页直接出现，不上浮。 |
| UI-S21 | 资料库或当前分类为空时，侧栏照常显示，内容区只有顶部的链接框。仍可按 ⌘V 或拖入链接来添加资料。 |

### 1.2.0：添加资料

| 编号 | 场景 |
|---|---|
| A-S1 | 资料库的每一页（全部、视频、播客、文章、论文）顶部都有链接框，跟列表一起滚动。提示按页面变，比如视频页是「粘贴视频链接，或把本地视频拖进来」；右边是「本地文件」。 |
| A-S2 | 在链接框里粘贴一个链接，左边的图标亮成琥珀色；按 Return，资料库多出一份并打开它，框清空。框里不是链接时按 Return 什么都不加。 |
| A-S3 | 点「本地文件」选文本、视频或音频文件，各自加入资料库；把本地视频或音频文件拖进资料库，作为视频或播客加入。 |
| A-S4 | 抖音、小红书、微博这类 yt-dlp 认得的视频链接，粘贴后作为视频加入，播放、下载、识别和 YouTube 一样；yt-dlp 不认得或那页没有视频的链接，照常作为文章读。 |
| A-S5 | 下载不再把网页读第二遍：yt-dlp 只在解析时读一次，下载接着用；读到的地址过期了才重新读。一段 19 分钟的 YouTube 视频，下载阶段少花一次解析的时间。 |

### β1：远程访问

设计稿是 `output/sketches/remote.html`（不提交），多台 Mac 时侧边栏用 V2。Loci 住在它的 Mac 上：看另一台时，看到和改动的是那台的 Loci（对话、Soul、记忆、日记、头像）和资料库。

| 编号 | 场景 |
|---|---|
| R-S1 | 只有一台 Mac：侧边栏和设置里看不到任何远程的东西；设置 › 远程只有居中的「添加 Mac…」。 |
| R-S2 | 两台 Mac 在同一局域网：一台点「添加 Mac…」，弹层里出现另一台；点它，两边显示同一个 4 位码，被连的一方点允许，几秒内两边的名单都多出对方。 |
| R-S3 | 两台 Mac 不在一起：一台点「使用邀请链接」并复制，另一台在任何地方 ⌘V，配对完成；链接用过一次或过期后再粘贴，说明它已失效。 |
| R-S4 | 配对后侧边栏底部出现当前 Mac 的名字；点开菜单选另一台，侧边栏换成那台的 Loci 和资料库，切回来回到原来的页面。 |
| R-S5 | 在远程的 Mac 上读资料、划线、问选段、和 Loci 对话：回复流式出现，延迟和本机相比只多中继的往返。 |
| R-S6 | 在远程的 Mac 上打开 PDF 和视频：PDF 下载时对话照常流式；视频能拖动进度。 |
| R-S7 | 远程的 Mac 睡眠或退出：侧边栏底部出现灰点，看过的内容（资料、主对话、Loci 页）照常能读，输入框位置显示「Mac Studio 离线」，写入按钮停用；它醒来后自动连上，小点消失。 |
| R-S8 | 设置 › 远程里移除一台 Mac：它立即断开，之后连不上，菜单里也没有它；再连需要重新配对。 |
| R-S9 | 两台 Mac 同时打开那台的主对话，任一边发消息，两边看到同一条流。 |
| R-S10 | 切到远程的 Mac 后，设置里的 Agent（Loci 用的 runtime）、媒体是那台的；外观和界面语言仍是这台的。 |
| R-S11 | 中继只看到密文：在中继上截获的流量里找不到资料、对话里的任何文字。 |
| R-S12 | 在远程的 Mac 上改 Loci 的 Soul、换头像、`/new`，改的是那台的 `agent/` 文件夹；这台的 Loci 不变。`agent/` 文件夹只能在它自己的 Mac 上用 Finder 打开。 |

## 不再用的词

删掉或改名一个东西时，把旧词加在这里，`script/check` 会列出所有还在用它的地方。拉丁字母的词不分大小写，按词首匹配。

| 词 | 改用 |
|---|---|
| 导师、mentor | Loci |
| 开始页 | 主对话 |
| 页边问答 | 划线（问答存进划线） |
| 设备组 | 配对 |
