# 功能地图

从用户的角度说 Loci 有什么、每样东西叫什么、怎样算做对。人和 agent 都用这里的词；代码里的类型名与这些词一一对应。新功能先在这里写场景，再写代码。

## 词汇

| 词 | 意思 | 代码里 |
|---|---|---|
| Loci | 唯一的 agent，有个性的通用伙伴；跑在本机已登录的 agent CLI 或应用自带的 Pi 上，人格和记忆是文件 | `LociAgent` |
| 在做什么 | Loci 回答时回复位置那一行淡字，从它正在用的工具说成一句人话 | `Doing` |
| 回答胶囊 | Loci 以提议结尾时，最后一个气泡下面能直接点的回答 | `QuickReplies` |
| Runtime | Loci 跑在什么上：provider、模型、思考强度。全应用一份；翻译和挑重点可以另选 | `Runtime` |
| 自带 Pi | 应用按需安装的 Pi，用模型服务的密钥运行 Loci | `BundledPiEnvironment` |
| 模型服务 | 用钥匙串里的密钥调用模型，给资料做翻译、章节和重点 | `ModelService` |
| 翻译设置 | 目标语言、智能翻译与文稿和文章的提示词 | `TranslationSettings` |
| 翻译缓存 | 按原文、模型、语言和提示词复用译文，可在设置里清除 | `TranslationCache` |
| 对话 | 用户看到的一条聊天：一条主对话，每份资料和每门课程各一条 | `Conversation` |
| 主对话 | 侧边栏第一项 Loci 打开的那条对话，一直聊下去；资料库里发生的事也出现在这里 | `ConversationRef.main` |
| 会话 | 对话底下的一次 agent CLI session；换 runtime、Soul 或 USER 变了、上下文满了就换新的，用户看不出 | `SessionRecord` |
| `/new` | 让对话下一条消息开新会话、不带之前的话；对话里留一条分隔线 | `StartOver` |
| 事件 | 资料库里发生、出现在主对话里的事：读完一份资料、你存进一份资料（带它的任务） | `WorldEvent` |
| 文档卡 | Loci 把长内容写成的文档，在对话里是一张能放大铺满的卡（`loci-doc` 块） | `DocumentCard` |
| 链接卡 | 回复里单独成行的链接：网页预览图、标题、站点；连着几张叠成一摞 | `LinkCard` |
| 资料卡 | 对话里的一份资料，和链接卡同一套样式 | `LibraryCard` |
| `loci` 命令 | 应用随包带给 Loci 的小程序：查资料库、存链接、导入它写的文章或下好的音视频、等任务跑完 | `LociCommand` |
| Soul | `SOUL.md`：核心（用户可改）和演化特质 | `Soul` |
| 演化特质 | 每日回顾给 Soul 加的一句话，带日期，最多 15 条 | `Trait` |
| 记忆 | `MEMORY.md` 里值得一直记得的事，只由每日回顾改 | `MemoryEntry` |
| 用户档案 | `USER.md`：怎么称呼、语言、做什么、为什么学 | `MemoryEntry`（`MemoryFile.profile`） |
| 笔记 | `notes/<日期>.md` 里的一行：时间、来自哪条对话、发生了什么；所有会话只往末尾追加 | `DayNote` |
| 日记 | `diary/<日期>.md`：Loci 每晚写给自己的，用户可以读 | `Diary` |
| 每日回顾 | 23:00 后空闲时的一次会话：写日记、整理记忆、可选加一条特质；错过了第二天补 | `DailyReview` |
| 在忙的事 | Loci 此刻在做的一件事：回答、刷新面板、每日回顾、处理一批资料；侧边栏左上角名字下面那行淡字说的就是它 | `LociWork` |
| 头像 | Loci 的形象；默认是应用自带的原创头像，用户可以换成自己的图片 | `Avatar` |
| 资料库 | 资料与课程的家 | `LibraryScreen` |
| 资料库分类 | 视频、播客、文章；论文归在文章里 | `LibraryCategory` |
| 资料 | 一份别人写的材料：文章、论文、视频、音频、仓库 | `Item` |
| 课程 | Loci 为你写的一串课时，资料库里的一类 | `Course` |
| 课时 | 课程里的一课：一个想法，5–10 分钟读完；标题是一个论断 | `Lesson` |
| 写课卡片 | 创建课程时的卡片：阶段尺、左边这门课的对话、右边桌面（扉页、资料、摊开的书） | `CourseBuilder` |
| 课程阶段 | 目标、资料、写课 | `CourseStage` |
| 课程目标 | 扉页上的东西：标题、副标题、为了什么、最要紧的、已经会的、深度、篇幅 | `CourseGoal` |
| 追问 | Loci 问的一个问题和它写的 2–4 个回答，可单选或多选 | `CourseQuestion` |
| 课程资料 | 一门课依据的一手资料：一个链接，仓库钉在一个提交上；不进资料库 | `CourseSource` |
| 文稿 | 视频或音频转录出的文字，一句一句带时间 | `Transcript` |
| 说话人 | 播客文稿中从 1 开始编号的人，能认出的名字可以修改 | `Speaker` |
| 单集页 | 打开一集播客的页面：小封面和信息、章节、按说话人分段的文稿 | `EpisodePage` |
| 正在播放 | 窗口里唯一在播的那一集播客或那个视频，归窗口不归页面；系统的正在播放也显示它 | `NowPlaying` |
| 播放条 | 播客播放时窗口底部常驻的一条，换页声音不停，关掉就停 | `PlayBar` |
| 视频小窗 | 视频播放中离开视频页时缩到内容区一角的小画面，可以交给系统画中画 | `VideoCorner` |
| 重点 | 你点了「挑重点」后，Loci 替一份视频、音频或文章挑出的几段，带标题和对你说的理由；存在 `keypoints.json` | `KeyPoint`、`KeyPoints` |
| 章节 | 视频或音频按时间分的段落，平台自带或 Loci 分 | `Outline.Chapter` |
| 译文 | 文稿或文章的另一种语言：文稿一句对一句，文章一段对一段 | `Translation`、`ArticleTranslation` |
| 任务 | 把一份资料变得可读的各个阶段：解析、取回页面、提取正文、找封面、下载、识别、区分说话人、翻译、章节；可以暂停、继续，取消就是删掉这份资料 | `Job` |
| 文章页面 | 取回的网页，能先读标题和封面，再从同一页面提取正文 | `ArticlePage` |
| 找封面 | 按平台缩略图、网页封面、正文合格图片和播客节目封面的顺序查找 | `CoverFinder` |
| 画廊 | 资料库的封面卡片视图：封面一样大，按加入的先后一行一行排 | `LibraryGallery` |
| 资料列表 | 资料库的一行一份视图，按列显示封面、标题、来源、类型、加入时间和阅读位置 | `LibraryList` |
| 纸面封面 | 没有图片时，在界面用纸色、站点首字的印章和站点名绘制的封面；不写标题 | `PaperCover` |
| 阶段尺 | 任务各阶段连成的一条尺：段长按工作量，做完的实色带 ✓，进行的琥珀带百分比，暂停斜纹，失败变红 | `StageRuler` |
| 任务胶囊 | 有任务时浮在画廊底部的玻璃胶囊，点开是任务列表 | `TaskDock` |
| 一批 | Loci 用 `loci save` 接连收进来、还在处理的那些资料；这时窗口四边亮起琥珀光 | `SavingBatch` |
| 存储 | 视频、播客和语音模型在这台 Mac 上占的空间；没有本地文件的资料在线看 | `StorageReport` |
| 取材缓存 | `loci read` 和 `loci repo` 取回的正文与仓库，14 天未使用自动清理 | `SourceCache` |
| 组件 | 应用调用但不自带的程序：yt-dlp、FFmpeg、QuickJS | `Component` |
| 语音模型 | 本机识别语音用的 Whisper 模型，七个型号按需下载 | `SpeechModel` |
| 更新 | 换上 GitHub 上发布的更新的 Loci (Beta)；只装同一张证书签名的版本 | `AppUpdate` |
| 链接框 | 资料库每页顶部的一条：粘贴链接加入，或从本地选文件 | `LinkField` |
| 导入卡片 | 收进一份视频、播客或本地音视频前浮出的卡片：怎么保存、字幕从哪来、翻不翻，和一句为什么收它 | `ImportSheet` |
| 导入选择 | 一份资料是怎么收进来的：保存到本地或在线看、画质、网站字幕或本机识别、翻译；下一次默认沿用 | `ImportChoice` |
| 为什么收它 | 收进来时写的一句话，显示在资料页标题下，陪读和挑重点都读得到 | `Item.why` |
| 内置浏览器 | 应用里的网页，用来登录网站、找视频、把正文加入资料库；一个窗口里可以有多个标签页 | `BrowserSession` |
| 标签页 | 内置浏览器里的一页，没有网页时是起始页 | `BrowserTab` |
| 网页浮层 | 在浏览器以外的地方点网页链接时，盖在窗口中间打开的那一页；沿用内置浏览器的登录，可以存进资料库或转到浏览器 | `WebOverlay` |
| 导入登录 | 内置浏览器带上这台 Mac 上 Chrome 等浏览器的登录状态；只属于这台 Mac，不经过远程 | `BrowserSignIns` |
| 陪读 | 打开一份资料时右栏和 Loci 的那条对话 | `ConversationRef.item` |
| 划线 | 读的时候留下的一条东西：一个位置，加上可有可无的想法和问答。英文界面叫 Highlights | `Note` |
| 定位符 | 指向资料或课时里某一处的地址：一句话、一段时间、几行代码、PDF 的一块 | `Locator` |
| 面板 | 主对话右边那一栏里的一块：Loci 替你盯着的一件事，由固定的行组成，按时刷新；「接着读」是自带的 | `Panel` |
| 右栏 | 阅读器右侧的栏：视频是文稿、重点、对话、划线，播客和文章是重点、对话、划线，论文是对话、划线 | `SideTab`、`MediaTab` |
| 字幕样式 | 字幕在画面上的样子：预设、译文和原文各自的字体字号颜色加粗、双语顺序、离底距离；存在这台 Mac 上 | `SubtitleStyle` |
| Host | 界面背后那套命令；本机和远程是同一套 | `Host` |
| 当前的 Mac | 界面此刻显示的那台 Mac 的数据；可以是这台，也可以是配对过的另一台 | `Machine` |
| 配对 | 两台 Mac 互相记下对方的公钥，之后都能打开对方 | `PairingStep` |
| 附近的 Mac | 同一局域网里开着 Loci 的 Mac | `NearbyMac` |
| 邀请链接 | 一次性的 `loci://pair/…`，在另一台 Loci 里粘贴即配对 | `Invite` |
| 中继 | 让不在同一网络的两台 Mac 连通的服务（alma-relay） | `Relay` |

每条场景有编号，派活和验收时引用编号。写法：前提、动作、看得到的结果。

|---|---|
| CO-S12 | 在 Loci 会话中用 `loci read <链接>` 匿名读网页、PDF、视频文稿或 GitHub 文件，用 `loci repo <链接> [--commit <sha>]` 取钉在一个提交上的只读浅克隆。取回的内容放在系统的取材缓存中，14 天未使用自动清理。设置 › 媒体 › 存储显示占用并可清空。Loci 的工作目录里不留下这些文件。 |

### Loci：agent、Soul、记忆（2026-11-18）

方案见 [agent.md](agent.md)，设计稿 `output/sketches/loci-agent.html`。

| 编号 | 场景 |
|---|---|
| L-S1 | 在主对话里说一句话，回复流式出现；退出再开，主对话都还在，续用同一个会话。 |
| L-S2 | 只输入 `/new`：对话里出现分隔线，之前的消息都还在；下一条消息开新会话，不带之前说过的话。 |
| L-S3 | 换 runtime、改 Soul、`USER.md` 变了、上下文用到 75% 或 agent 自己压缩了上下文：下一条消息开新会话，带上最近的问答接着聊，对话里看不出换过。 |
| L-S4 | 在一份资料的对话里问第一个问题，Loci 知道这是哪份资料、正文和划线在哪；选段提问答完存进那条划线；主对话和资料对话可以同时在答。 |
| L-S5 | 每条消息前带着现在的时间与时段、上次说话以来资料库里发生的事、最近在读的资料；`MEMORY.md` 和今天、昨天的笔记只在没发过或变了时再附，笔记过长只留最后一段。 |
| L-S6 | 设置里选的 runtime 是全局一份；下一轮用新的 provider、模型和思考强度。导入卡片的翻译和重点页可以另选运行时与模型，默认跟随 Loci。 |
| L-S7 | 23:00 后、10 分钟没说话、没有回合在跑：Loci 回顾这一天，写日记、整理 `MEMORY.md`、可选加一条特质；每天一次，错过了第二天补，什么都没发生的日子不回顾；回顾时侧边栏的小点亮着。 |
| L-S8 | Loci 页显示 Soul 核心（可编辑保存，特质不变）、特质（新的在前）、记忆（日期与出处）、`USER.md`、今天的笔记（时间与来自哪条对话）、日记、相处天数与对话数与一起读过的资料数；在访达里改这些文件，页面跟着变；删一条记忆只删那一行；格式不对的行原样显示。 |
| L-S9 | 读完一份资料、从界面存进一份资料，主对话里在当时的位置出现一条事件；还在取回、转录的资料带着任务进度；资料删了，事件也不见。 |
| L-S10 | 换头像后各处一起变，恢复默认后回到自带头像。 |

### Loci 往资料库里放东西

Loci 自己的东西（记忆、笔记）直接写文件；资料库读文件，查和写用 `loci` 命令。用法就是 `loci help` 的文字，见 `Sources/LociModel/Local/ToolGuide.swift`。

| 编号 | 场景 |
|---|---|
| L-S11 | 在主对话里让 Loci 存一个链接：它跑 `loci save <链接>`，资料库立刻多出这份资料并开始取回；这一轮回复里出现这份资料的预览卡片，点开就是它。 |
| L-S12 | Loci 存进的资料不在主对话里另出现一条「存进」事件，下一轮也不再当作新发生的事告诉它；从界面存的照旧（L-S9）。 |
| L-S13 | 在一份资料的对话里让 Loci 找一篇相关的论文存下：预览卡片出现在这条对话里，主对话里没有。 |
| L-S14 | 让 Loci 写一篇总结放进资料库：它在 `workspace/` 写好 Markdown，跑 `loci import`；资料库多出一篇作者是 Loci、没有来源的文章，`--title` 给的标题优先于正文的标题。 |
| L-S15 | Loci 下好的视频或音频，`loci import` 后复制进资料库并开始转录。 |
| L-S16 | Loci 用 `loci search` 查资料库，得到 id、标题和命中的那句话；`loci show` 看一份资料的种类、任务和它的文件夹；`loci wait` 等到取回完成，失败或在等用户时说出原因并以 1 退出。 |
| L-S17 | 应用没开、或不是在 Loci 的会话里跑 `loci`：它说清楚原因并以 1 退出；命令写错以 2 退出并给出正确写法；`loci help` 不用应用也能看。 |
| L-S18 | `loci` 只能做上面这几件事，别的 Host 命令一律拒绝；它连的 socket 在数据文件夹的 `run/` 里，只有本机这个用户进得去。 |

### 界面改版（2026-11-17）

设计稿是 `output/sketches/redesign.html`（不提交），规则见 design.md 的「设计」。

| 编号 | 场景 |
|---|---|
| UI-S1 | 窗口没有工具栏；侧边栏是悬浮的玻璃面板，红绿灯在它里面。 |
| UI-S2 | 侧边栏顶部是 Loci（见 H-S1、H-S2），下面是资料库（全部、视频、播客、文章、浏览器），然后是设置（通用、Agent、模型服务、媒体、远程）。配对后底部显示当前 Mac 的名字，切到另一台时隐藏模型服务（见 R-S4）。点 Loci 进主对话；已经在主对话时再点进 Loci 页面。 |
| UI-S3 | 主对话像发消息：Loci 的一条回复按空行分成几个气泡（代码、列表、表格、公式、引用各自整块），气泡样式见 C-S9。隔一小时以上出现日期分隔：一条细线，下面居中一行小字。新消息上浮淡入。 |
| UI-S4 | 资料右栏顶部一行：小分段居中（文章「对话 / 划线」，视频「文稿 / 对话 / 划线」，播客「对话 / 划线」），右边是收起按钮，不放头像和名字。收起后窗口右上角留一个玻璃按钮重新打开。没有选人。 |

## 不再用的词

删掉或改名一个东西时，把旧词加在这里，`script/check` 会列出所有还在用它的地方。拉丁字母的词不分大小写，按词首匹配。

| 词 | 改用 |
|---|---|
| 导师、mentor | Loci |
| 开始页 | 主对话 |
| 页边问答 | 划线（问答存进划线） |
| 设备组 | 配对 |
| 保留划线 | 删除资料一律连划线一起删，可以撤销 |
| 书架 | 画廊 |
| 自动重点 | 点了才挑的重点 |
| 播客大字 | 单集页 |
| 步骤卡、StepsCard、ToolTitle、ToolTally | 在做什么（`Doing`），对话里不再出现思考和工具 |
| ContextGauge | 对话里不再显示上下文用量 |
| 导入面板 | 导入卡片 |
| PanelTab | 右栏（`SideTab`） |
| SidebarFit | `PaneFit` |
| kind.paper、link.promptPaper | 文章分类和它的链接框 |
| 下一课卡片、NextLessonCard | 课时目录 |
| 瀑布流 | 画廊 |
