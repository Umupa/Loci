# Loci Roadmap

> 公开维护（build in public）。一个版本做完，挪进「已完成」并写上发布的版本号，再用 `script/cut-release` 发版，见 [releasing.md](releasing.md)。

## 定位

**Loci 是一个 Mac 应用：从你读的、看的、听的东西里学习，身边有一个住在你资料库里的 AI 伙伴，替你跟进你在意的领域。**

- **一个伙伴。** 名字由你决定，跑在你本机已登录的 agent CLI 上，没装的话用应用自带的 Pi 和你的模型服务 key，可以随时换 runtime；人格和记忆是 `agent/` 下的文件，换了 runtime 还是同一个伙伴。
- **一个资料库。** 文章、论文、视频、播客粘一个链接就能读；视频和播客在本机转录，带章节、重点和逐句译文。
- **一起读。** 每份资料旁边都有一条和伙伴的对话；选中一句话就能划线、写想法、问它。
- **替你跟进。** 连上 GitHub、Gmail、Notion、X 这些你常去的地方，伙伴按时去看，有值得的事先开口；首页的面板替你盯着。它只看、只帮你弄懂，不替你办事。
- **本地优先。** 数据留在本机，没有账号服务，没有统计。另一台 Mac 配对后可以远程打开；数据仍只在它自己的 Mac 上。

### 不做什么

- 不做掌握度考核、答题判定和间隔复习排期。读到底就算读完；想检验时自己说「考我」。
- 伙伴替你找，应用替伙伴取：应用只取回一个确定的链接，找资料是伙伴的事。
- 不做给人刷的信息流和 RSS 阅读器：跟进什么由你和伙伴说定，伙伴读完只把值得的告诉你。
- 不替你办事：不下单、不付款、不报名、不替你发消息。连接器只用来读。
- 不做剪辑与导出、上云，也不做给人用的命令行。`loci` 命令只给伙伴用。
- 不做 agent harness，也不做通用的 agent CLI 外壳。

## 接下来

### 1.7.9：主页布局

- 主对话和面板栏作为一组居中；面板拖到任一栏或新开一栏，对话左右换位，栏宽可拖，布局按钮一键换排法，每台 Mac 记自己的布局。
- 长面板在一行结束处截断；窗口窄时远处的栏折成一枚小胶囊里的来源小图标。
- 场景 P-S1、P-S2、P-S9、P-S11–P-S16。设计稿 `output/sketches/companion-layout/index.html`（不提交）。


### 1.7.10：可编辑面板

- 面板分三层：形状由伙伴按你的话搭，条目各有主人（你或伙伴），你的态度（勾选、置顶、隐藏、备注）挂在条目上，刷新后保留。
- 你在面板里直接加、勾、改、排序、删除，⌘Z 撤销；伙伴可以提议或主动加条目，但不改你写的字、不删你的条目。没有应用里的固定整理规则，也没有绕过伙伴的空白面板。
- 写入从「伙伴整份重写文件」改为经面板管家的一条条操作，`loci panel` 沿用条目 ID 并校验不碰你的条目。
- 场景 P-S17–P-S24。设计稿 `output/sketches/editable-panels/index.html`（不提交）。
### 1.5.0：替你跟进

- **连接器。** 设置里一页，分「已连接」和「可连接」。来源是 runtime 已经有的（`gh` 的登录、配置好的 MCP server）和内置浏览器里登录过的网站；应用不另做授权。只读。
- **定时。** 设置里一页，列出伙伴按时去看的事：名字、频率、发到主对话。在对话里说「每天晚上九点看看 CubeSandbox」就加一条。
- **简报。** 定时的结果出现在主对话，上面一行「晚间简报」；只说一件值得的事，以一个提议结尾；没什么值得说就不说。
