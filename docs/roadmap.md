# Loci Roadmap

> 更新于 2026-10-31。这份路线图公开维护（build in public），按阶段推进，每个阶段完成后再细化下一个。

## 定位

**Loci 是给工程师的 AI native 学习工作台：一位常驻的导师，带你读一手材料、读源码、动手实验，直到你真正学会。**

- **一个导师，一个主题。** 每个导师是一个长期存在的 agent：有自己的 Soul（长期指令）、记忆、资料库、课程和工作目录。
- **一手材料，不是 AI 总结。** 导师负责采集官方文档、规范、论文和源码；你读的是原文，导师在旁边陪你读。
- **真 agent，能动手。** 导师背后是你本机已登录的 Claude Code 或 Codex，能 clone 仓库、跑代码、做实验，不需要另配 API key。
- **本地优先。** 数据留在本机，没有账号，没有统计。

### 学习循环

```
目标 → 一手材料 + 课程 → 导师陪你读 → 读码 / 实验 → 用自己的话沉淀 → 导师记住，下次接着带
       （导师采集）      （选中即问）                （笔记 / 画布）
```

效率来自消掉五种摩擦：找资料、在工具间切换、每次重新交代上下文、中断后难以重新开始、读完不等于懂。

### 不做什么

- 不做掌握度考核门槛、答题证据判定和间隔复习排期。读到底就算读完；想检验时由你自己说"考我"。
- 应用里不写爬虫。抓取是导师（agent）的能力，Loci 提供存储、阅读和课程这些底层原语。
- 不把 Loci 做成通用的 agent CLI 外壳。和学习无关的功能会被删掉。

## 阶段

### M0｜定位与减法（进行中）

目标：打开应用后看到的每样东西都和学习有关。

- 改写 README（中英文）和应用内文案，换成上面的定位。
- 删除与学习无关的功能：
  - Ledger（市场日报）模板
  - 会话提醒
  - 会话文件夹、`/add-to-folder`、会话筛选
  - 项目吉祥物、项目 Logo、项目专属聊天背景、按项目的通知设置
  - 用量仪表与账号管理
  - `/operator` 命令入口（底层 control 通道保留，导师的 `app` 命令依赖它）
  - 欢迎动画、发送特效、回合庆祝
- 模板只保留 **Mentor**（学一个主题）和 **Lens**（学一个代码库）。
- 10 个 CLI 的适配代码保留；只保证 Claude Code 与 Codex，其余标成实验性。

完成标准：上面这些都已删除，`npm run check` 全部通过。

### M1｜新的信息结构与布局

目标：从选导师、读课文、提问到回到上次读的位置，全程在一个窗口里完成，不开新标签。

- 侧边栏就是导师列表，一个导师一个主题；去掉 Projects 区块。
- 导师工作台采用"目录在左、原文居中、对话在右"的三栏布局（2026-10-31 选定方案 B）：
  - 左栏：课程目录与资料库（课程 / 资料 / 笔记 / 画布），可折叠；
  - 中间：阅读区，打开任何资料都只替换这里；
  - 右栏：导师对话，当前课文作为上下文。
- 拆掉多标签与分栏系统（tab 分组、置顶、停放、总览、切换器）。
- 每个导师有自己的工作目录，存放 clone 的源码和实验文件，取代 Projects。
- 导师资料库分四区：资料、课程、笔记、画布。
- 不属于导师的独立会话在界面上隐藏；导师委派子任务时作为内部机制保留。

### M2｜陪你读

- 统一阅读器：文档、PDF、课程都有目录、高亮和批注（目前只有 PDF 支持高亮批注）。
- 任何选中的内容都能直接问导师。
- 正在读的课和段落自动作为上下文带给导师，不必手动 Add to chat。
- 导师回复可以链接到原文的具体位置（基于 `loci://source`）。
- 打开导师时回到上次读到的位置。

### M3｜读码

- 代码导览课成为一等课型：在导师工作目录里读源码，配合 diff 讲解与"改一行看效果"。
- 源码阅读沿用 M2 的阅读器：高亮、批注、选中即问。

### M4｜实验

- 导师在工作目录里准备练习；阅读区可以切成终端或文件视图，你自己跑，或者导师带你跑。
- 可选：接入沙箱，跑需要隔离的实验。

### M5｜沉淀

- 画布用来画你自己的心智模型；"讲给导师听"的费曼模式。
- 导出（例如到 Obsidian），课程与资料可以打包分享。

### 以后再说

首次启动引导、habit 与导师主动跟进、Today 首页、学习者画像。现有的 habit 代码保留，但不再投入。
