# Loci Roadmap

> 更新于 2026-11-01。这份路线图公开维护（build in public），按版本推进，每个版本完成后再细化下一个。

## 定位

**Loci 是给工程师的 AI native 学习工作台：一位常驻的导师，带你读一手材料、读源码、动手实验，直到你真正学会。**

- **一个导师，一个主题。** 每个导师是一个长期存在的 agent：有自己的 Soul（长期指令）、记忆、资料库、课程和工作目录。
- **一手材料，不是 AI 总结。** 导师负责采集官方文档、规范、论文和源码；你读的是原文，导师在旁边陪你读。
- **真 agent，能动手。** 导师背后是你本机已登录的 agent CLI（Claude Code、Codex、Antigravity 等），能 clone 仓库、跑代码、做实验，不需要另配 API key。
- **本地优先。** 数据留在本机，没有账号，没有统计。

### 学习循环

```
目标 → 一手材料 + 课程 → 导师陪你读 → 读码 / 实验 → 用自己的话沉淀 → 导师记住，下次接着带
       （导师采集）      （选中即问）                （笔记 / 画布）
```

效率来自消掉五种摩擦：找资料、在工具间切换、每次重新交代上下文、中断后难以重新开始、读完不等于懂。

### 不做什么

- 不做掌握度考核门槛、答题证据判定和间隔复习排期。读到底就算读完；想检验时由你自己说"考我"。
- 应用里不写爬虫。抓取是导师（agent）的能力，Loci 提供存储、阅读和课程这些底层原语。
- 不把 Loci 做成通用的 agent CLI 外壳。和学习无关的功能会被删掉；但各家 agent CLI 的适配都保留，导师可以跑在任意一家上。

## v0.2（已发布，2026-11-01）

- **M0｜定位与减法。** README 与文案换成新定位；删除用量仪表与账号管理、会话提醒、会话文件夹与筛选、`/operator`、Ledger 模板、装饰动画、按项目的背景与通知设置。
- **M1｜新的信息结构与布局。** 左侧导师栏（一个导师一个主题）；导师工作台为"目录在左、原文居中、对话在右"的三栏布局；拆掉多标签、分栏与 Projects；每个导师有自己的工作目录（`~/Loci/<名字>`）；⌘K 搜索导师与资料库；回到导师时回到上次的页面。

## v0.3（进行中）：导师质量 + 和导师一起阅读

**验收方式：** 用户把自己的沙箱学习（CubeSandbox、SPACE、E2B runtime）完整搬到 v0.3 上，连续一周学习不需要离开 Loci。评估与端到端验证默认让导师跑在 **Antigravity CLI（`agy`）** 上。

### 1. 导师默认 Full access

- 导师的对话默认使用 Full access 权限模式，不再频繁弹授权；已有导师一并切换。
- 设置里可以改回其他模式（按导师，或全局默认）。

### 2. Loci CLI：所有功能都能从命令行完成

- 把应用的全部能力同步开放为 CLI：导师（创建、列出、改设置、发消息、读回复）、课程、资料、笔记、画布、工作目录、阅读区（打开某课某段）、会话、设置。
- 两个用途：
  - **测试：** 端到端测试通过 CLI 驱动真实运行的 Loci，覆盖"建导师 → 采集资料 → 排课 → 阅读 → 提问"整条链路，不再依赖人工点击。
  - **外部 agent 当导师：** 外部的 Claude Code、Codex、Antigravity 等可以通过 CLI 创建课程、写入资料、在阅读区打开内容，扮演导师角色。
- UI 与 CLI 共用同一套命令层，新功能必须同时有 CLI 入口。
- 本机访问需要鉴权（本机令牌），默认只允许当前用户。

### 3. 左侧栏重新设计：顺手的学习工作台

- 现状的问题：课程目录在最上方，下面的 COURSES 又列一遍同一门课；资料、笔记、画布、文件挤在一条长滚动里；文件树很长；文件工具栏有 5 个图标。
- 目标：左栏以"我正在学什么、下一步读哪里"为中心，课程目录、资料库、文件各有清晰的位置，切换顺手，按钮少。
- 2026-11-01 选定方案 A「顶部分段切换」：顶部四个分段（课程 / 资料 / 笔记（含画布）/ 文件），一次只看一类；课程分段依次是课程切换（课名 ▾）、进度、"继续阅读"卡片和目录。
- 同一门课只出现一次；目录高亮并自动滚到当前课，章节可折叠；文件区只留一个 "…" 菜单；筛选框作用于当前分段；空分区只占一行。
- 已实现（分支 `v0.3/mentor-sidebar`）：在课程切换里选一门课会直接打开它的下一课；命令行用 `loci library open/show` 切换分段、课程和筛选。

### 4. 和导师一起阅读（原 M2）

- 统一阅读器：文档、Markdown、PDF、源码都有目录、高亮和批注（目前只有 PDF 支持高亮批注）。
- 任何选中的内容都能直接问导师。
- 正在读的课和**段落**自动作为上下文带给导师，不必手动 Add to chat。
- 导师回复可以链接并跳转到原文的具体位置（基于 `loci://source`）。

### 5. 导师质量与评估

- 评估工具：用 3–5 个真实主题（例如 K8s 调度、CubeSandbox 源码、一篇论文），通过 Loci CLI 驱动 Mentor / Lens 模板跑完整流程，导师跑在 Antigravity 上。
- 评分维度：资料是否一手、课程结构是否循序渐进、回答是否引用到原文、首次对话的十分钟体验。
- 根据评估结果重写模板：定目标、选资料、排课、陪读答疑。
- 已知问题：`documents.write` 强制要求 `sourceUrl`，导师自写的导读进不了资料库；需要区分"一手资料"与"导师导读"。

### 6. 自用验收

- 把沙箱学习迁到 v0.3；在 Loci 里记一份"卡点日志"笔记，边用边修。

### 推进顺序

1. 第一批并行：导师 Full access（1）、Loci CLI 设计与实现（2）、左侧栏草图与选型（3）。
2. 第二批：左侧栏实现（3）、和导师一起阅读（4）、评估工具（5，依赖 CLI）。
3. 第三批：根据评估重写模板（5）、自用验收（6）。

## 之后的版本

### 读码（原 M3）

- 代码导览课成为一等课型：在导师工作目录里读源码，配合 diff 讲解与"改一行看效果"。
- 源码阅读沿用 v0.3 的阅读器：高亮、批注、选中即问。

### 实验（原 M4）

- 导师在工作目录里准备练习；阅读区可以切成终端或文件视图，你自己跑，或者导师带你跑。
- 可选：接入沙箱，跑需要隔离的实验。

### 沉淀（原 M5）

- 画布用来画你自己的心智模型；"讲给导师听"的费曼模式。
- 导出（例如到 Obsidian），课程与资料可以打包分享。

### 以后再说

首次启动引导、habit 与导师主动跟进、Today 首页、学习者画像。现有的 habit 代码保留，但不再投入。
