# Loci Roadmap

> 公开维护（build in public）。一个版本做完，挪进「已完成」并写上发布的版本号，再用 `script/cut-release` 发版，见 [releasing.md](releasing.md)。

## 定位

**Loci 是一个 Mac 应用：从你读的、看的、听的东西里学习，身边有一个住在你资料库里的 AI 伙伴，替你跟进你在意的领域。**

- **一个伙伴。** 名字由你决定，跑在你本机已登录的 agent CLI 上，没装的话用应用自带的 Pi 和你的模型服务 key，可以随时换 runtime；人格和记忆是 `agent/` 下的文件，换了 runtime 还是同一个伙伴。
- **一个资料库。** 文章、论文、视频、播客粘一个链接就能读；视频和播客在本机转录，带章节、重点和逐句译文。
- **一起读。** 每份资料旁边都有一条和伙伴的对话；选中一句话就能划线、写想法、问它。
- **替你跟进。** 连上 GitHub、Notion、日历、邮件、X 这些你常去的地方，伙伴按时去看，看到的放进首页的面板、记在心里，你说话时它都知道。信息流由伙伴先筛过再给你；只要数字的，由应用直接取，不经过模型。
- **项目。** 一件长期的事（投资、一次旅行、一轮面试）有自己的对话、面板、定时和记忆，不污染主对话。
- **替你办一点事。** 能撤回的写操作（放进日历、加一条提醒、在 Notion 建一页），每一次都先给你一张批准卡，你点了才做。
- **本地优先。** 数据留在本机，没有账号服务，没有统计。另一台 Mac 配对后可以远程打开；数据仍只在它自己的 Mac 上。

### 不做什么

- 不做掌握度考核、答题判定和间隔复习排期。读到底就算读完；想检验时自己说「考我」。
- 伙伴替你找，应用替伙伴取：应用只取回一个确定的链接，找资料是伙伴的事。
- 不做给人刷的信息流和 RSS 阅读器：跟进什么由你和伙伴说定，信息流先经规则和伙伴筛过，只把值得的给你。你关注的博主和节目只在关注页里列出新的一期，你挑中的才进资料库。
- 不替你办撤不回的事：不下单、不付款、不报名、不替你发消息。写操作只走批准卡，一次一张；连接器、数据源和带登录的网页照旧只读。
- 不做剪辑与导出、上云，也不做给人用的命令行。`loci` 命令只给伙伴用。
- 不做 agent harness，也不做通用的 agent CLI 外壳。
- 不做服务端：伙伴住在你的一台 Mac 上，不收 webhook，按时去看。

## 接下来

### 关注

你信得过的博主和节目，有新的一期就在 Loci 里看到，不用自己去翻。资料库里一个关注只占一张头像，点开才是往期列表；你挑中的那一期才进资料库、才下载（FO-S1–FO-S8）。

- **来源。** YouTube 频道：新的一期读频道的公开 RSS（只有最近 15 条），往期用 `yt-dlp --flat-playlist` 列。小宇宙节目：读节目网页，或从 Apple 播客查到的 RSS；这台机器直连张小珺那档节目的 RSS 被对方的 IP 白名单拒过，做的时候在真机上定用哪条。播客 RSS 和 Apple 播客链接直接读。
- **取数。** 沿用数据源的取数线和总预算，只发 GET；只有新的一期才写数据库、亮小点。
- **不做。** B 站 UP 主（要登录和签名，下一步再看）；YouTube 播放列表；伙伴判断每一期值不值得看；自动下载；通知。

### 项目、数据源与下一步余下

1.8.4 发布时留下的、很少碰到的时序边角：

- **项目关闭和后台交错。** 批准卡确认后、真正写入前归档或删除项目，写入仍会发生；回顾、取数后的分拣待办、修数据源入队、连接器审计在项目移走后仍可能补写一笔。都改成沿用开始时的项目代次，或在移动边界内提交。
- **批准写入的对账。** 外部条目被移到别的日历、列表或时段后，启动对账可能判为不存在并重新开放批准。
- **修数据源的许可。** 可重试失败复用同一个 run，旧尝试的回放可能借新许可保存；`source list` 跨 run 结束可能失去名称过滤。每次尝试单独签发许可。
- **数据源。** 解析超时后 WebKit 不回调时，停止等待只靠回调结清。
- **修好与否。** 保存成功后模型断线，修好的消息不发。
- **定时与私密项目。** 工具准入和路由之间 run 结束，动作可能落到主对话；「不进记忆」后再次换会话仍会从全部旧消息生成 recap。
- **开发版数据。** 跑过 1552cb04 那一版的数据库，旧格式的下一步卡片读不出来（发布版没有这个功能，不影响用户）。
- **没在真机验过：** 普通卡片的留着、稍后、不要（悬停动作）；折线图悬停十字线；需要登录的数据源；第二台 Mac；减弱动效。

### 更新：增量

二进制补丁、跨版本的更新说明、换上失败回滚、隔离位置提示（UP-S8–UP-S11）。

- 实测 1.8.6 → 1.8.7：dmg 74 MB；包里 361 个文件只变了 7 个，但这 7 个有 200 MB（主程序 154 MB、`loci` 30 MB、whisper 15 MB）。重新签名会让每个可执行文件都变，按文件替换省不下来；二进制差分后主程序 12 MB，`loci` 和 whisper 各约 5 KB。
- 应用用系统自带的 `/usr/bin/bspatch` 打补丁，不加依赖；发布流水线用 bsdiff 为最近几个版本各生成一份补丁，并写每个文件的 SHA-256 清单。
- 完整包从 dmg 换成 zip（或 Apple Archive），安装时不再挂载映像；dmg 只留给第一次下载。
- `latest.json` 带最近几个版本的 CHANGELOG 段落，供 UP-S9 合并。
- 不做：Ed25519 清单和 Sigstore 证明（同一张证书的签名要求已是信任的锚点，补丁打完照样整包验签）、多渠道、多下载源、静默若干天。
