# Loci Roadmap

> 更新于 2026-11-17。这份路线图公开维护（build in public），按版本推进，每个版本完成后再细化下一个。0.2 到 0.11 是 Tauri 版，记录在 `main` 分支。

## 定位

**Loci 是给工程师的 AI native 学习工作台：一位常驻的导师，为你写课、讲透原理，每个论断都能一键回到一手材料。**

- **一个导师，一个主题。** 每个导师是一个长期存在的 agent：有自己的 Soul（长期指令）、记忆、目录和工作目录。
- **资料库和导师并列。** 文章、论文、视频、播客、代码仓库都是独立的资料，粘一个链接就能读；任意一位导师都可以陪读。只有课引用资料。
- **导师写课，一手材料作证据。** 课文是导师按你的基础写的讲解：问题、机制、图、例子、取舍。官方文档、规范、论文和源码由导师采集，作为每个论断的出处，点一下就能看原文；想深入时再读原文。
- **真 agent，能动手。** 导师背后是你本机已登录的 agent CLI（Claude Code、Codex、Grok、Antigravity 等），能 clone 仓库、跑代码、做实验，不需要另配 API key。
- **本地优先。** 数据留在本机，没有账号服务，没有统计。其他设备可以远程连到这台主机；数据仍只存在主机上，客户端只缓存看过的内容。

### 学习循环

```
目标 → 全景图 + 路径 → 读导师写的课 → 在课上提问 → 课文随提问修订 → 用得上
       （导师采集出处）  （出处一键可查）  （问答留在课上）             （面试怎么讲 / 对照手头的系统）
```

效率来自消掉五种摩擦：找资料、读不懂原文、每次重新交代上下文、中断后难以重新开始、读完不等于懂。

### 不做什么

- 不做掌握度考核门槛、答题证据判定和间隔复习排期。读到底就算读完；想检验时由你自己说"考我"。
- 应用只取回一个确定的链接（一篇文章、一段视频），不替你找资料。找什么值得读是导师的事。
- 不做订阅与 RSS、剪辑与导出、上云、命令行。
- 不把 Loci 做成通用的 agent CLI 外壳。和学习无关的功能会被删掉；但各家 agent CLI 的适配都保留，导师可以跑在任意一家上。

## v1.0（规划中）：原生 Swift 版，导师与资料库并列

2026-11-17 决定。方案设计见 [design.md](design.md)。

- **两个入口。** 学一个主题（导师），或消化一份材料（资料库）。资料是独立的原子，不绑定导师；只有课引用资料。打开资料时可以选任意一位导师陪读。
- **新的资料种类。** 视频与技术演讲、播客：本机转录、双语文稿随播放同步、章节与重点、引用到秒。文章粘链接即读。
- **全部用 Swift 重写。** SwiftUI 加 AppKit，只做 macOS 26 及以上；Windows 和 Linux 停止。界面换成系统材质、系统控件和系统动效；视觉选定「暖夜」：暖黑底、琥珀强调色、胶囊控件、大圆角。
- **重新设计数据。** 内容是文件，状态在数据库。不兼容旧数据。
- **远程访问对齐。** 界面只认一套命令，本机和远程是同一套。
- **去掉命令行。** 导师通过自己文件夹里的文件和应用协作。
- **不做：** RSS 与订阅、剪辑与导出、上云。

原生版在 Loci Dev 渠道按 α0 到 β2 推进；Tauri 版冻结在 0.11.x，只修影响使用的问题。

| 版本 | 主题 |
|---|---|
| α0 | 验证与选型：阅读器、驱动、视频、远程四个限时验证；视觉草图 |
| α1 | 骨架与数据 |
| α2 | 导师与读课 |
| α3 | 资料库：文章 |
| α4 | 资料库：视频与播客 |
| α5 | 读码 |
| β1 | 远程访问 |
| β2 | 打磨与发布 |

## 之后的版本

- iPhone 与 iPad 端：同一套 Host 协议，换一个界面。
- 由导师代管的订阅：导师自己盯更新，只产出课文修订或一条近况，没有收件箱。
- 实验：导师在工作目录里准备练习，你自己跑或导师带你跑。
- 讲给导师听的费曼模式；课程与资料打包分享。
- 元数据上云。
